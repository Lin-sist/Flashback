## 1. 当前报错结论
- 本次登录失败的直接原因不是账号 `admin / 123456` 错了，而是后端先连数据库失败了。
- 根因日志是：`java.sql.SQLException: Access denied for user 'root'@'localhost' (using password: YES)`

- 当前开发配置文件是 [application-dev.yml](C:\_01_Code\Flashback\backend\src\main\resources\application-dev.yml)，数据库连接支持通过环境变量覆盖。

## 10. 常见故障对照
- `Access denied for user`：用户名或密码错
- `Unknown database`：数据库没建
- `doesn't exist`：表没建
- `Communications link failure`：MySQL 没启动或端口不通
- `Connection refused`：后端服务或依赖服务没启动
- `401`：token 丢失、过期或请求头没带
- `400 nickname不能为空`：前端注册参数不完整
