# 《时光回序》前端开发版 Markdown（Copilot / Codex 用）

> 用途：本稿用于 Uniapp + Vue 3 前端开发落地、Copilot 代码生成、Codex 结构审查。  
> 范围：冻结页面职责、页面结构、导航规则、页面显隐、核心样式方向。  
> 不在本稿冻结范围内：高级动效、接口细节、自动保存实现方式、异常态策略、分页与搜索算法。

---

## 0. 开发阶段总原则

### 0.1 当前阶段目标

当前项目已经完成页面定稿，进入前端工程落地阶段。

当前阶段优先级：
1. 页面职责正确
2. 导航关系正确
3. 页面结构正确
4. 样式层级接近定稿
5. 基础交互可用
6. 高级动效后置

### 0.2 当前阶段禁止事项

开发过程中不得擅自：
- 新增一级 Tab
- 把“我的档案”改成一级 Tab
- 把首页改成管理页
- 给新建页、解锁页加入标准顶部栏或底部导航
- 把时间轴改成图表页、多列流布局或管理页
- 把个人中心改成内容流页面
- 擅自删除定稿中的关键视觉元素

### 0.3 一级导航固定规则

一级底部导航固定为 3 个：
- 首页
- 时间轴
- 个人中心

非一级页面：
- 我的档案
- 新建页
- 解锁页
- 各类详情页

## 1. 全局视觉与结构规则

### 1.1 整体气质
- 安静
- 私密
- 克制
- 温柔
- 有时间感

### 1.2 视觉方向
- 冷灰白背景
- 低饱和蓝灰主色
- 大圆角
- 大留白
- 中文主叙事
- 英文仅作弱辅助

### 1.3 全局样式基础值

#### 颜色
- 页面主背景：`#F8FAFB`
- 容器背景：`#FFFFFF`
- 主蓝灰色：`#3B647A`
- 辅助正文深色：`#1A1A1A`
- 次级文字灰：`#7F8C93`
- 暖米色容器：`#FFFDF5`
- 极淡米色强调：`#FDF2D9`

#### 圆角
- 超大圆角：`32px`
- 大圆角：`28px`
- 中圆角：`24px`
- 小圆角：`8px`
- 胶囊圆角：`999px`

#### 间距
- 页面左右边距：`24px`
- 大模块主间距：`32px`
- 常规模块间距：`20px`
- 列表项间距：`16px`
- 容器内边距：`32px`

#### 字号建议
- 页面主标题：`26px`
- 强调大数字：`32px`
- 二级标题：`18px`
- 正文：`16px`
- 次级正文：`14px`
- 辅助信息：`12px`

### 1.4 字体策略
- 中文主叙事允许使用衬线气质标题
- 功能信息、列表信息、输入正文优先使用系统无衬线
- 首版工程允许全部落回系统字体，不强制接入自定义字体包

### 1.5 导航显隐总规则

#### 显示底部导航
- 首页
- 时间轴
- 个人中心

#### 隐藏底部导航
- 我的档案
- 新建页
- 解锁页
- 详情页

#### 使用右上角 X
- 新建页
- 解锁页

#### 使用返回箭头
- 我的档案
- 其他普通二级页

## 2. 页面定义

## 2.1 首页

### 页面定位
私人时间档案馆入口页。

### 页面职责
- 展示草稿入口
- 展示封存摘要
- 展示最近解锁摘要
- 提供“我的档案”入口
- 提供新建入口

### 不负责
- 搜索
- 筛选
- 批量管理

### 页面结构
1. 顶部导航层：中置品牌标题 + 右侧历史图标
2. 情绪标题区：中文大标题 + 单行说明文案
3. 核心摘要卡片区：
   - 草稿入口大卡
   - 封存记录总数卡
   - 最近解锁记忆卡
4. 管理入口区：我的档案入口卡
5. 底景装饰区：静物摄影图
6. 悬浮层：右下角 FAB
7. 底部导航

### 样式规则
- 页面背景固定 `#F8FAFB`
- 首页主卡与入口卡默认圆角 `32px`
- 模块间距默认 `20px`
- Hero 标题与内容区主间距默认 `32px`
- 首页卡片阴影可略强于其他页面
- 最近解锁卡允许极淡米色偏移

### 不可改动
- 大标题首屏主视觉地位
- 静物底图
- 我的档案入口卡
- 悬浮 + 按钮
- 3 Tab 底部导航

---

## 2.2 我的档案

### 页面定位
首页延伸页 / 档案管理中心。

### 页面职责
- 展示全部档案
- 搜索
- 状态筛选
- 列表浏览
- 进入详情页

### 不负责
- 一级导航
- 首页式展陈
- 悬浮主操作

### 页面结构
1. 顶部导航层：返回箭头 + 标题
2. 搜索与筛选层：
   - 搜索框
   - 全部 / 草稿 / 已封存 / 已解锁筛选
3. 统计摘要层：当前列表总数
4. 档案列表层：纵向列表
5. 底部装饰层：弱化收尾文案与点阵

### 样式规则
- 背景固定 `#F8FAFB`
- 列表卡默认圆角 `28px`，允许在 `24px - 32px` 内微调
- 搜索框为胶囊圆角
- 列表卡阴影为极浅单层阴影
- 列表项间距默认 `16px`
- 状态标签可使用低饱和功能色

### 不可改动
- 顶部返回箭头
- 底部导航隐藏
- 搜索框 + 筛选页签组合
- 列表式管理结构

---

## 2.3 新建页

### 页面定位
沉浸式书写与封存页。

### 页面职责
- 书写内容
- 展示封存主操作
- 提供轻量附加入口
- 关闭时返回来源页

### 不负责
- 内容浏览
- 管理操作
- 复杂跳转

### 页面结构
1. 顶部功能层：左侧 `Vol.` 编号 + 右侧 X
2. 标题引导层：`Captured at` + 中文日期主标题
3. 纸张容器层：白色主书写纸张
4. 竖排标识层：纸张右上侧竖排标识
5. 正文输入区：大面积无边框输入区
6. 附加入口层：`MAP / IMAGE / VOICE`
7. 主动作区：底部“封存这一刻”按钮

### 样式规则
- 背景固定 `#F8FAFB`
- 主纸张容器默认圆角 `32px`
- 纸张内部 padding 默认 `32px`
- 日期标题默认 `28px`
- 正文默认 `16px`，行高 `1.8`
- 主按钮为蓝灰色胶囊按钮
- 整体不引入额外高饱和色

### 不可改动
- 沉浸式结构
- 右上角 X
- 白色大纸张容器
- `Vol.` / `Captured at` / 竖排标识
- `MAP / IMAGE / VOICE`
- 底部主按钮

---

## 2.4 解锁页

### 页面定位
沉浸式旧信阅读页 / 情绪峰值页。

### 页面职责
- 阅读旧信正文
- 展示顶部元信息
- 提供轻量回应输入

### 不负责
- 标准详情管理
- 多功能操作面板
- 标准导航显示

### 页面结构
1. 顶部元信息层：点阵背景 + `ARCHIVE NO.` + 时间 / 地点信息 + X
2. 信纸容器层：米色旧信纸容器
3. 正文排版区：大段正文
4. 装饰点缀层：信纸内部弱装饰
5. 回应容器层：下方半透明输入容器
6. 回应操作层：容器内“留下回应”按钮

### 样式规则
- 背景主色仍为 `#F8FAFB`
- 页面允许极轻点阵背景
- 信纸容器使用 `#FFFDF5`
- 信纸默认圆角 `8px`
- 正文默认 `16px`，行高 `1.9`
- 回应容器为半透明白色
- 本页允许明显偏暖

### 不可改动
- 小圆角旧信纸容器
- 偏暖正文区
- 顶部元信息
- 右上角 X
- 下方回应容器与按钮

## 2.5 时间轴

### 页面定位
回望叙事页 / 时间长廊。

### 页面职责
- 用单列纵向时间线展示记录
- 展示不同类型节点
- 提供时间叙事感

### 不负责
- 复杂筛选管理
- 图表分析
- 多列流布局

### 页面结构
1. 顶部导航层：左侧搜索图标 + 中置品牌标题
2. 长廊标题区：大标题“时间长廊” + 说明文案
3. 时间轴容器层：纵向单列主体
4. 纵向轴线层：偏左细实线
5. 节点流层：
   - 纯文本锁定节点
   - 高光内容卡节点
   - 已解锁暖色节点
6. 收尾装饰层：底部文案与点阵
7. 底部导航

### 样式规则
- 背景固定 `#F8FAFB`
- 轴线偏左布局，左侧建议预留 `48px`
- 节点主间距默认不少于 `40px`
- 高光卡片默认圆角 `32px`
- 长廊标题默认 `26px`
- 日期信息默认 `12px`
- 已解锁节点允许局部暖色偏移

### 不可改动
- 单列纵向时间轴
- 左搜索 + 中置标题
- 长廊 Hero 区
- 纯文本节点与高光卡混合结构
- 底部导航
