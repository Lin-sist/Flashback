# 《时光回序》页面级设计样式与工程规格说明（封版稿）

## 首页 页面级设计样式与工程规格说明

### 1. 页面定位

**私人时间档案馆入口页。**
本页面是产品的一级主入口，负责承载首页展陈感与核心入口分发。页面通过草稿入口、封存摘要、最近解锁摘要、“我的档案”入口以及新建按钮，构成用户进入各主要内容路径的起点。
首页不承担复杂筛选、搜索、批量管理职责。

### 2. 页面入口与退出

* **进入**：应用启动默认主入口；点击底部导航“首页”进入。
* **退出**：

  * 点击底部导航切换至“时间轴”或“个人中心”；
  * 点击草稿入口、摘要卡片或“我的档案”入口进入对应二级页面；
  * 点击右下角悬浮“+”进入新建页。
* **返回逻辑**：作为一级根页面，不显示返回按钮。

### 3. 导航显示规则

* **顶部栏**：显示。采用极简结构，中置品牌标题，右侧为历史图标，左侧留白。
* **底部导航**：显示。固定 3 Tab：首页 / 时间轴 / 个人中心。
* **返回/关闭按钮**：不显示返回箭头，不显示右上角 X。
* **主动作入口**：右下角固定悬浮“+”按钮。

### 4. 页面结构分区

1. **顶部导航层**：品牌标题与历史图标。
2. **情绪标题区**：大字号中文叙事标题与单行辅助说明文案。
3. **核心摘要卡片区**：

   * 草稿入口大卡；
   * 两张次级摘要卡，分别承载封存记录总数与最近解锁记忆。
4. **管理入口区**：通栏圆角卡片，作为“我的档案”快捷入口。
5. **底景装饰区**：底部静物摄影图，用于增强氛围感。
6. **悬浮层**：右下角悬浮新建按钮。

### 5. 页面视觉样式规则

* **背景**：`#F8FAFB`，全局冷灰白，不允许偏移。
* **容器样式**：白色卡片容器，配轻量弥散阴影。
* **圆角**：

  * 首页主卡与入口卡默认 `32px`；
  * 底部导航容器默认顶圆角 `32px`。
* **留白**：

  * 页面左右边距默认 `24px`；
  * Hero 标题区与下方内容的主间距默认 `32px`；
  * 模块间垂直间距默认 `20px`，允许在 `16px - 20px` 内微调。
* **文字层级**：

  * 主标题默认 `26px`，中文为视觉主叙事；
  * 正文与说明文字默认 `15px`。
* **色彩偏移**：仅“最近解锁”摘要卡允许使用极淡米色偏移，其他区域保持冷灰白与蓝灰主色体系。

### 6. 页面关键组件

* **TopAppBar**：显示品牌标题与历史图标，无返回按钮。
* **BottomNavBar**：本页为首页激活态。
* **DraftEntryCard**：首页主草稿入口卡，承载“继续完成当前草稿”的入口感。
* **SummaryStatCard**：用于展示封存总数与最近解锁摘要。
* **ManagementEntryCard**：用于进入“我的档案”。
* **FloatingActionButton**：右下角悬浮新建按钮。

### 7. 页面状态说明

* **默认态**：正常展示草稿入口、摘要卡片、管理入口和底景图。
* **空态**：当暂无记录时，摘要区应保留首页结构与整体留白，不改动首页入口页定位。
* **滚动态**：页面允许纵向滚动，首页展陈结构不变。

### 8. 页面不可改动的视觉特征

1. 首页的大圆角包裹感必须保留。
2. 中文大标题必须占据首屏视觉中心。
3. 首页必须保留底部静物图与右下角悬浮“+”的组合关系。
4. 首页必须维持“展陈入口页”属性，不能演变为管理页。

### 9. 页面允许微调的部分

* 底景图片的裁切比例与透明感；
* 卡片阴影的模糊半径与透明度；
* 辅助英文标签的字号与字距；
* 卡片之间的细部间距。

### 10. 页面与全局系统的差异边界

* 首页主卡圆角强制高于普通列表页；
* 首页卡片阴影可以略强于“我的档案”页；
* 严禁在首页加入复杂筛选、列表管理、批量操作；
* 严禁改成多列复杂网格布局。

## 我的档案 页面级设计样式与工程规格说明

### 1. 页面定位

**首页延伸页 / 档案管理中心。**
本页面负责展示全部记录，并提供搜索、状态筛选与列表浏览能力。
它是首页的延伸管理页，不是一级 Tab，不是第二个首页。

### 2. 页面入口与退出

* **进入**：从首页点击“我的档案”入口卡片进入。
* **退出**：

  * 点击顶部左侧返回按钮返回首页；
  * 点击档案条目进入对应详情页。

### 3. 导航显示规则

* **顶部栏**：显示。左侧返回箭头，中置标题“我的档案”。
* **底部导航**：隐藏。
* **返回/关闭按钮**：使用左上角返回箭头。
* **额外操作入口**：不显示悬浮“+”按钮。

### 4. 页面结构分区

1. **顶部导航层**：返回按钮与标题。
2. **搜索与筛选层**：

   * 全通栏搜索框；
   * 横向状态筛选页签：全部 / 草稿 / 已封存 / 已解锁。
3. **统计摘要层**：显示当前列表总数。
4. **档案列表层**：纵向滚动的档案条目列表。
5. **底部装饰层**：极简收尾文案与装饰点阵。

### 5. 页面视觉样式规则

* **背景**：`#F8FAFB`。
* **容器样式**：白色列表卡片，单层极浅阴影。
* **圆角**：

  * 列表条目卡默认 `28px`，允许在 `24px - 32px` 内微调；
  * 搜索框使用胶囊圆角；
  * 筛选页签使用小圆角。
* **留白**：

  * 页面左右边距默认 `24px`；
  * 列表项垂直间距默认 `16px`。
* **文字层级**：

  * 分区标题默认 `18px`；
  * 摘要正文默认 `14px`，行高 `1.6`。
* **色彩偏移**：状态标签允许使用低饱和功能色区分不同状态。

### 6. 页面关键组件

* **TopAppBar**：返回键 + 标题。
* **SearchBar**：关键词搜索入口。
* **FilterSegmentControl**：状态筛选入口。
* **ArchiveListItem**：列表核心组件，展示标题、摘要、时间与状态。
* **FooterHint**：底部弱化引导文案。

### 7. 页面状态说明

* **默认态**：展示全部档案列表。
* **筛选态**：按状态切换当前列表内容。
* **空态**：当某状态下无内容时，展示极简占位文案，保持页面留白风格。
* **滚动态**：顶部栏固定，列表纵向滚动。

### 8. 页面不可改动的视觉特征

1. 我的档案必须保留“管理页”属性。
2. 列表卡片必须保持圆润大圆角，不可改成硬朗工具风。
3. 中文标签必须作为主信息呈现。
4. 页面不显示底部导航，不显示首页悬浮“+”。

### 9. 页面允许微调的部分

* 搜索占位文案；
* 条目阴影深度；
* 图标线宽；
* 列表卡内部细节间距。

### 10. 页面与全局系统的差异边界

* 本页强制隐藏底部导航；
* 本页允许更高信息密度，但不能变成后台管理系统；
* 本页圆角可低于首页，但必须明显大于解锁页的信纸圆角。

## 新建页 页面级设计样式与工程规格说明

### 1. 页面定位

**沉浸式书写与封存页。**
本页面用于用户写下内容并完成封存，是产品的核心创作页。
页面重点是安静、私密、无干扰的书写体验。

### 2. 页面入口与退出

* **进入**：从首页右下角悬浮“+”进入。
* **退出**：

  * 点击右上角 X 关闭；
  * 关闭时自动保存当前内容为草稿并返回来源页。
* **返回逻辑**：返回进入该页前的来源页面。

### 3. 导航显示规则

* **顶部栏**：不显示标准顶部栏。
* **底部导航**：不显示。
* **返回/关闭按钮**：仅显示右上角 X。
* **额外操作入口**：不显示菜单、搜索、历史等入口。

### 4. 页面结构分区

1. **顶部功能层**：左侧 `Vol.` 编号，右侧 X。
2. **标题引导层**：`Captured at` 辅助文案与中文日期主标题。
3. **纸张容器层**：全屏主白色书写纸张。
4. **竖排标识层**：纸张右上侧竖排档案标识。
5. **正文输入区**：无边框大面积文本输入区。
6. **附加入口层**：纸张底部的 `MAP / IMAGE / VOICE` 三个轻量入口。
7. **主动作区**：底部独立主按钮“封存这一刻”。

### 5. 页面视觉样式规则

* **背景**：`#F8FAFB`。
* **容器样式**：白色纸张容器，带柔和弥散阴影。
* **圆角**：

  * 纸张容器默认 `32px`；
  * 主按钮使用胶囊圆角。
* **留白**：

  * 页面左右边距默认 `24px`；
  * 纸张内部 padding 默认 `32px`。
* **文字层级**：

  * 日期标题默认 `28px`，中文衬线气质；
  * 输入正文默认 `16px`，行高 `1.8`。
* **色彩偏移**：整体保持冷灰白与蓝灰主色，不引入额外彩色主视觉。

### 6. 页面关键组件

* **PaperContainer**：主书写纸张容器。
* **CloseXButton**：右上角关闭出口。
* **WritingInput**：无边框正文输入区。
* **StatusIconGroup**：MAP / IMAGE / VOICE 轻量入口。
* **SealButton**：底部主操作按钮。

### 7. 页面状态说明

* **默认态**：展示占位文案与可输入纸张容器。
* **输入态**：键盘弹出，页面保持输入焦点在可视区。
* **关闭返回态**：点击 X 后保存草稿并退出。
* **封存态**：点击“封存这一刻”后进入封存流程，具体反馈与跳转由后续交互文档定义。

### 8. 页面不可改动的视觉特征

1. 新建页必须是沉浸式页面。
2. 白色大纸张容器与底部主按钮的组合关系必须保留。
3. 右上角 X 是唯一明确出口。
4. `Vol.`、`Captured at`、竖排档案标识与底部三枚轻量入口应视为定稿视觉的一部分。

### 9. 页面允许微调的部分

* 日期标题字距；
* 纸张阴影扩散半径；
* 底部三枚轻量入口的图标线宽；
* 纸张内部文字区高度与留白。

### 10. 页面与全局系统的差异边界

* 本页强制隐藏顶部与底部标准导航；
* 本页主容器强制使用更大的圆角；
* 本页允许更强的留白与更低的信息密度；
* 本页不承载管理操作与复杂功能入口。

## 解锁页 页面级设计样式与工程规格说明

### 1. 页面定位

**沉浸式旧信阅读页 / 情绪峰值页。**
本页面用于阅读已解锁的旧信内容，并承载一段轻量回应输入。
页面核心是“阅读过去的自己”，而不是功能操作。

### 2. 页面入口与退出

* **进入**：从首页摘要卡或“我的档案”条目进入。
* **退出**：点击右上角 X 返回来源页。
* **返回逻辑**：从首页进入则返回首页，从“我的档案”进入则返回“我的档案”。

### 3. 导航显示规则

* **顶部栏**：不显示标准顶部栏。
* **底部导航**：不显示。
* **返回/关闭按钮**：仅显示右上角 X。
* **额外操作入口**：不显示分享、菜单、举报等显性图标。

### 4. 页面结构分区

1. **顶部元信息层**：点阵背景、`ARCHIVE NO.`、时间信息、地点信息与右上角 X。
2. **信纸容器层**：米色旧信纸主容器。
3. **正文排版区**：信纸内部的大字号衬线主叙事内容。
4. **装饰点缀层**：信纸底部装饰性弱图形。
5. **回应容器层**：信纸下方的半透明输入容器。
6. **回应操作层**：回应容器内的主按钮“留下回应”。

### 5. 页面视觉样式规则

* **背景**：`#F8FAFB`，叠加极轻点阵背景。
* **容器样式**：

  * 主信纸容器使用偏暖米色 `#FFFDF5`；
  * 回应容器使用半透明白色。
* **圆角**：

  * 信纸容器默认 `8px`；
  * 回应按钮使用胶囊圆角。
* **留白**：

  * 页面左右边距默认 `24px`；
  * 信纸内部 padding 默认 `32px`。
* **文字层级**：

  * 正文默认 `16px`，行高 `1.9`；
  * 顶部元信息与占位文案使用低对比辅助文字。
* **色彩偏移**：本页是全局唯一允许明显转暖的页面。

### 6. 页面关键组件

* **AncientPaperCard**：旧信纸主容器。
* **CloseXButton**：右上角关闭出口。
* **LetterMetaInfo**：顶部编号、时间、地点信息。
* **PostscriptInput**：轻量附言输入区。
* **ResponseButton**：容器内主按钮“留下回应”。

### 7. 页面状态说明

* **默认态**：展示完整正文与回应输入容器。
* **输入态**：软键盘弹出后，附言输入区域保持在可视区。
* **空态**：不适用，本页必须有内容才能进入。
* **回应提交态**：按钮触发回应流程，具体反馈由后续交互文档定义。

### 8. 页面不可改动的视觉特征

1. 旧信纸的小圆角与偏暖色调必须保留。
2. 正文必须优先于操作区，保持阅读中心。
3. 右上角 X 是唯一显性退出方式。
4. 点阵背景与顶部元信息层应视为页面氛围的重要组成部分。

### 9. 页面允许微调的部分

* 米色背景的饱和度；
* 正文行高；
* 回应容器透明度；
* 顶部元信息字重与字距。

### 10. 页面与全局系统的差异边界

* 本页是全局圆角最小的页面；
* 本页是全局唯一允许正文主容器明显偏暖的页面；
* 本页必须保持沉浸式阅读页属性，不能工具化；
* 本页不显示标准导航，不显示列表式管理控件。

## 时间轴 页面级设计样式与工程规格说明

### 1. 页面定位

**回望叙事页 / 时间长廊。**
本页面以单列纵向时间线的方式回望用户记录。
页面重在叙事感与时间感，不承担复杂管理职责。

### 2. 页面入口与退出

* **进入**：点击底部导航“时间轴”进入。
* **退出**：点击底部导航切换至“首页”或“个人中心”。

### 3. 导航显示规则

* **顶部栏**：显示。中置标题“时光回序”，左侧为搜索按钮，右侧留白。
* **底部导航**：显示。固定 3 Tab，本页为激活态。
* **返回/关闭按钮**：不显示返回箭头，不显示 X。
* **额外操作入口**：不显示悬浮“+”或侧边栏入口。

### 4. 页面结构分区

1. **顶部导航层**：搜索图标与品牌标题。
2. **长廊标题区**：大标题“时间长廊”与说明文案。
3. **时间轴容器层**：纵向单列时间轴主体区域。
4. **纵向轴线层**：偏左布局的细实线时间轴。
5. **节点流层**：

   * 纯文本锁定节点；
   * 高光内容节点卡；
   * 已解锁暖色高光节点。
6. **收尾装饰层**：底部文案与弱化点阵收尾。
7. **底部导航层**：全局 Tabbar。

### 5. 页面视觉样式规则

* **背景**：`#F8FAFB`。
* **容器样式**：

  * 高光节点卡使用白色或偏暖色填充；
  * 轴线与节点点位使用低对比蓝灰色。
* **圆角**：

  * 高光卡片默认 `32px`；
  * 状态标签使用小圆角。
* **留白**：

  * 页面左右边距默认 `24px`；
  * 轴线偏左布局，左侧建议预留 `48px`；
  * 节点间主间距默认不少于 `40px`。
* **文字层级**：

  * 长廊主标题默认 `26px`；
  * 日期信息默认 `12px`，字距略放大。
* **色彩偏移**：已解锁节点允许局部偏暖，用于体现“被唤醒”的温度感。

### 6. 页面关键组件

* **TopAppBar**：左侧搜索按钮 + 中置标题。
* **TimelineAxis**：纵向时间轴线。
* **TimelineNode**：普通节点。

## 个人中心 页面级设计样式与工程规格说明

### 1. 页面定位

**静态控制页 / 个人档案控制页。**
本页面负责承载用户资料、档案设置、隐私与安全、版本信息等控制类内容。
它不是内容浏览页，也不是时间叙事页。

### 2. 页面入口与退出

* **进入**：点击底部导航“个人中心”进入。
* **退出**：点击底部导航切换至“首页”或“时间轴”。

### 3. 导航显示规则

* **顶部栏**：显示。中置品牌标题，右侧保留轻量溢出菜单入口。
* **底部导航**：显示。固定 3 Tab，本页为激活态。
* **返回/关闭按钮**：不使用返回箭头，不使用 X。
* **额外操作入口**：不显示悬浮“+”。

### 4. 页面结构分区

1. **顶部导航层**：品牌标题与右侧更多入口。
2. **个人资料区**：头像、昵称、签名。
3. **统计卡片区**：已存记忆 / 存档天数双卡布局。
4. **设置分组区**：

   * 档案设置；
   * 隐私与安全；
   * 关于。
5. **退出操作区**：页面底部文字型退出入口。
6. **底部导航层**：全局 Tabbar。

### 5. 页面视觉样式规则

* **背景**：`#F8FAFB`。
* **容器样式**：统计卡与设置分组使用白色容器，配极轻阴影。
* **圆角**：

  * 分组卡与统计卡默认 `32px`；
  * 一级设置项保持统一大圆角容器语言。
* **留白**：

  * 页面左右边距默认 `24px`；
  * 分组间垂直间距默认 `24px`，允许在 `24px - 32px` 微调。
* **文字层级**：

  * 统计数字默认 `32px`；
  * 设置项标题默认 `16px`。
* **色彩偏移**：右侧“存档天数”卡允许使用极淡米色背景。

### 6. 页面关键组件

* **TopAppBar**：中置标题 + 右侧更多入口。
* **ProfileHeader**：头像、昵称、签名。
* **StatisticCard**：双卡统计组件。
* **SettingGroupCard**：分组设置容器。
* **BottomNavBar**：本页为个人中心激活态。

### 7. 页面状态说明

* **默认态**：展示资料、统计与设置分组。
* **滚动态**：顶部栏固定，内容区域纵向滚动。
* **控制态**：点击设置项进入对应二级控制页。

### 8. 页面不可改动的视觉特征

1. 页面必须保留“静态控制页”的秩序感；
2. 头像、昵称与统计卡必须形成首屏主层级；
3. 分组卡必须保持大圆角与高留白；
4. 退出入口必须保持弱化处理，不抢主视觉。

### 9. 页面允许微调的部分

* 统计卡阴影深度；
* 列表项图标样式；
* 退出入口的垂直位置；
* 签名字号与颜色对比度。

### 10. 页面与全局系统的差异边界

* 本页是一级页面中最偏“控制感”的页面；
* 本页不承担内容展示与情绪主叙事；
* 本页不显示悬浮新建按钮；
* 本页顶部允许保留轻量溢出菜单，但不应出现重操作图标。
