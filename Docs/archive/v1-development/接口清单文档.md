# 《时光回序》接口清单文档（V2.0 M4）

## 1. 通用规范

### 1.1 接口前缀

| 前缀 | 说明 |
| --- | --- |
| `/api/auth/**` | 认证接口，部分无需登录 |
| `/api/user/**` | 当前用户接口，需要登录 |
| `/api/records/**` | 记录、位置、附件、封面、回信与时光轴接口，需要登录 |
| `/api/tags/**` | 标签接口，需要登录 |
| `/api/ai/**` | AI 辅助接口，需要登录 |
| `/api/stage-summaries/**` | 阶段总结接口，需要登录 |

### 1.2 认证方式

除注册、登录、微信登录等白名单接口外，用户侧接口通过 JWT 鉴权：

```http
Authorization: Bearer <token>
```

后端通过 `JwtAuthenticationInterceptor` 校验 token，并通过 `@CurrentUser AuthUser` 注入当前用户。

### 1.3 统一返回体

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

常用错误码：

| code | 说明 |
| --- | --- |
| `40000` | 参数错误或非法生命周期操作 |
| `40100` | 未登录或 token 无效 |
| `40300` | 无权限 |
| `40400` | 资源不存在 |
| `50000` | 内部错误或上游服务不可用 |

### 1.4 分页约定

普通列表使用 `pageNum`、`pageSize`。时光轴接口为 M4 特化分页：

- `pageNum` 默认 1，最小 1。
- `pageSize` 默认 20，最大 50。
- 排序固定为 `created_at DESC, id DESC`。
- 先分页记录，再按 `createdAt` 年月分组。

## 2. 认证模块

### 2.1 注册

```http
POST /api/auth/register
```

请求：

```json
{
  "username": "testuser",
  "password": "password123",
  "nickname": "测试用户"
}
```

响应：`RegisterResponseVO`，包含用户基本信息。

规则：

- `username` 唯一。
- 密码只保存哈希。
- 注册成功后可继续登录获取 token。

### 2.2 账号密码登录

```http
POST /api/auth/login
```

请求：

```json
{
  "username": "testuser",
  "password": "password123"
}
```

响应：`LoginResponseVO`，包含 token 与用户信息。

### 2.3 微信登录

```http
POST /api/auth/wechat-login
```

请求：

```json
{
  "code": "wx-login-code"
}
```

规则：

- 后端使用 `WECHAT_MINI_PROGRAM_APP_ID` 和 `WECHAT_MINI_PROGRAM_SECRET` 调用微信 `code2session`。
- 不信任前端传入的 OpenID。
- 微信配置缺失时必须显式失败，不签发假登录。

## 3. 用户模块

### 3.1 获取当前用户

```http
GET /api/user/me
```

响应：`UserInfoVO`。

### 3.2 修改个人资料

```http
PUT /api/user/profile
```

请求：

```json
{
  "nickname": "新的昵称",
  "email": "user@example.com",
  "avatar": "https://example.com/avatar.png"
}
```

响应：`UserInfoVO`。

## 4. 记录模块

### 4.1 创建草稿

```http
POST /api/records
```

请求：`CreateRecordRequest`

```json
{
  "title": "写给三个月后的自己",
  "content": "此刻我正在准备一次重要选择。",
  "recordType": "NODE_RECORD",
  "coreQuestion": "我真正担心的是什么？",
  "tagIds": [1, 2],
  "unlockAt": "2026-09-01T09:00:00",
  "aiSummary": "可选 AI 整理结果",
  "aiPromptResults": ["可选提示结果"],
  "beliefThen": "你当时以为..."
}
```

响应：`RecordDetailVO`。

说明：

- 创建记录主体只处理文本、类型、标签、解锁时间等字段。
- 位置、附件、封面使用独立子资源接口。

### 4.2 编辑草稿

```http
PUT /api/records/{id}
```

请求：`UpdateRecordRequest`，字段与创建草稿类似。

规则：

- 仅 `DRAFT` 可编辑。
- 用户只能编辑自己的记录。
- 封存和解锁后拒绝编辑。

### 4.3 删除草稿

```http
DELETE /api/records/{id}
```

规则：

- 仅 `DRAFT` 可删除。
- 用户只能删除自己的记录。

### 4.4 封存记录

```http
POST /api/records/{id}/seal
```

规则：

- 仅 `DRAFT` 可封存。
- 封存后状态变为 `SEALED`。
- 封存后正文、位置、附件、封面不可变。

### 4.5 更新后来其实

```http
PUT /api/records/{id}/later-reflection
```

请求：

```json
{
  "realityLater": "后来我发现..."
}
```

规则：

- 用于解锁后的时间回看补充。
- 遵循后端已接受的提交次数和生命周期规则。

### 4.6 更新解锁提醒授权

```http
PUT /api/records/{id}/unlock-reminder-authorization
```

请求：

```json
{
  "templateType": "UNLOCK_REMINDER",
  "accepted": true
}
```

规则：

- 用于记录微信订阅消息授权结果。
- 订阅消息缺配置时应返回明确状态，不影响记录主生命周期。

### 4.7 我的记录列表

```http
GET /api/records
```

查询参数：

| 参数 | 说明 |
| --- | --- |
| `status` | 可选，`DRAFT` / `SEALED` / `UNLOCKED` |
| `pageNum` | 页码 |
| `pageSize` | 每页数量 |

响应：分页记录列表，记录项包含基础字段、标签、可选 `cover`、可选 `locationLabel`。

### 4.8 我的已解锁记录

```http
GET /api/records/unlocked
```

用途：时间回看入口和已解锁记录列表。

### 4.9 时光轴

```http
GET /api/records/timeline
```

查询参数：

| 参数 | 说明 |
| --- | --- |
| `tagId` | 可选，只支持一个 enabled/shared 标签 |
| `year` | 可选，`1970..9999` |
| `month` | 可选，`1..12`，必须先提供 `year` |
| `day` | 可选，合法日，必须先提供 `year` 和 `month` |
| `pageNum` | 默认 1 |
| `pageSize` | 默认 20，最大 50 |

响应：`TimelinePageVO`

```json
{
  "groups": [
    {
      "yearMonth": "2026-06",
      "items": []
    }
  ],
  "total": 42,
  "pageNum": 1,
  "pageSize": 20,
  "hasMore": true
}
```

规则：

- 日期语义使用记录 `createdAt`，业务时区为 `Asia/Shanghai`。
- 标签和日期使用 AND 语义。
- 排序固定 `created_at DESC, id DESC`。
- 合法但无匹配数据返回成功空页。
- 非法年月日组合返回 `40000`。

### 4.10 记录详情

```http
GET /api/records/{id}
```

响应：`RecordDetailVO`

M4 扩展字段：

- `location`
- `attachments`
- `cover`

规则：

- owner-scoped。
- 解锁后的时间回看展示位置、图片、语音和封面时，仍保持只读。

## 5. 记录位置模块

### 5.1 更新位置

```http
PUT /api/records/{id}/location
```

请求：`UpdateRecordLocationRequest`

```json
{
  "source": "MAP_PICKER",
  "name": "人民公园",
  "address": "上海市黄浦区南京西路",
  "latitude": 31.2317,
  "longitude": 121.4746
}
```

规则：

- `source` 为 `CURRENT_LOCATION`、`MAP_PICKER` 或 `MANUAL`。
- `CURRENT_LOCATION` 和 `MAP_PICKER` 需要经纬度。
- `MANUAL` 至少需要 `name` 或 `address`。
- 仅 `DRAFT` 可更新。
- 后端不做地理编码。

### 5.2 删除位置

```http
DELETE /api/records/{id}/location
```

规则：

- 仅 `DRAFT` 可删除。
- 封存/解锁后拒绝。

## 6. 附件与封面模块

### 6.1 获取上传授权

```http
POST /api/records/{recordId}/attachments/upload-token
```

请求：`CreateAttachmentUploadTokenRequest`

```json
{
  "type": "IMAGE",
  "fileName": "example.jpg",
  "mimeType": "image/jpeg",
  "sizeBytes": 123456
}
```

响应：`AttachmentUploadTokenVO`

```json
{
  "provider": "QINIU",
  "bucket": "flashback-private",
  "key": "flashback/users/1/records/10/image/uuid.jpg",
  "uploadMethod": "POST_MULTIPART",
  "uploadUrl": "https://upload.qiniup.com",
  "fileFieldName": "file",
  "uploadHeaders": {},
  "uploadFormData": {
    "token": "short-lived-token",
    "key": "flashback/users/1/records/10/image/uuid.jpg"
  },
  "expiresAt": "2026-06-17T12:00:00",
  "maxFileSizeBytes": 41943040
}
```

规则：

- owner-scoped。
- 记录必须是 `DRAFT`。
- `type` 只能是 `IMAGE` 或 `VOICE`。
- 每条记录最多 9 张图片、9 条语音。
- 单文件最大 40 MB，单记录总附件最大 300 MB。
- 后端生成或批准对象 key，不接受任意 client key。

### 6.2 提交并校验附件

```http
POST /api/records/{recordId}/attachments/commit
```

请求：`CommitRecordAttachmentRequest`

```json
{
  "provider": "QINIU",
  "type": "IMAGE",
  "key": "flashback/users/1/records/10/image/uuid.jpg",
  "fileName": "example.jpg",
  "mimeType": "image/jpeg",
  "sizeBytes": 123456,
  "width": 1200,
  "height": 800,
  "durationSeconds": null
}
```

响应：`RecordAttachmentVO`。

规则：

- 后端必须调用当前 provider 校验对象存在。
- 校验 size、MIME 和 key 归属后才写入附件元数据。
- 校验失败返回明确失败，不写入假成功附件。

### 6.3 获取媒体访问 URL

```http
GET /api/records/{recordId}/attachments/{attachmentId}/access-url
```

响应：`AttachmentAccessUrlVO`

```json
{
  "attachmentId": 1,
  "url": "https://private-domain/key?signature=...",
  "expiresAt": "2026-06-17T12:00:00"
}
```

规则：

- 返回私有桶短时访问 URL。
- 默认有效期 600 秒，可后端配置。
- URL 不作为永久状态存库。

### 6.4 删除附件

```http
DELETE /api/records/{recordId}/attachments/{attachmentId}
```

规则：

- 仅 `DRAFT` 可删除。
- 使用附件持久化的 `storageProvider` 路由到对应 provider。
- 远端删除成功或对象已不存在后才清理元数据。
- 如果删除的是当前封面图片，封面引用应被清理。

### 6.5 更新封面

```http
PUT /api/records/{id}/cover
```

请求：

```json
{
  "attachmentId": 1
}
```

清空封面：

```json
{
  "attachmentId": null
}
```

规则：

- 仅 `DRAFT` 可修改。
- 封面必须是同记录、同用户、`IMAGE`、`AVAILABLE` 附件。
- 不支持独立封面上传。

## 7. 回信模块

### 7.1 创建回信

```http
POST /api/records/{recordId}/reply
```

请求：`CreateReplyRequest`

```json
{
  "content": "现在回看，我想对当时的自己说..."
}
```

规则：

- 仅 `UNLOCKED` 记录可回信。
- 单记录最多一条回信。

### 7.2 查询回信

```http
GET /api/records/{recordId}/reply
```

响应：`ReplyVO` 或空。

## 8. 标签模块

### 8.1 标签列表

```http
GET /api/tags
```

查询参数：

| 参数 | 说明 |
| --- | --- |
| `type` | 可选，`SYSTEM` / `USER` |
| `enabledOnly` | 可选，是否只返回启用标签 |

响应：`List<TagVO>`。

## 9. AI 模块

### 9.1 写作提示

```http
POST /api/ai/writing-prompts
```

请求：`AiWritingPromptsRequest`

```json
{
  "content": "我现在有点焦虑，不知道怎么写。",
  "recordType": "NODE_RECORD"
}
```

响应：`AiWritingPromptsVO`

关键字段：

- `prompts`
- `source`
- `status`: `SUCCESS` / `UNAVAILABLE` / `FAILED` / `FALLBACK`
- `message`

### 9.2 内容整理

```http
POST /api/ai/summarize-record
```

请求：`AiSummarizeRecordRequest`

```json
{
  "content": "今天发生了很多事..."
}
```

响应：`AiSummaryVO`。

规则：

- AI API Key 只存在于后端配置。
- 真实用户路径缺配置或上游失败时必须显式失败。
- AI 结果不能替代用户原始正文。

## 10. 阶段总结模块

### 10.1 生成阶段总结

```http
POST /api/stage-summaries/generate
```

响应：`StageSummaryVO`。

规则：

- 复用 AI provider 能力。
- 上游失败应返回明确不可用/失败状态，不应让前端误判为真实成功。

## 11. 接口鉴权矩阵

| 接口 | 是否需要登录 | 说明 |
| --- | --- | --- |
| `POST /api/auth/register` | 否 | 注册 |
| `POST /api/auth/login` | 否 | 账号密码登录 |
| `POST /api/auth/wechat-login` | 否 | 微信 code 登录 |
| `/api/user/**` | 是 | 当前用户 |
| `/api/records/**` | 是 | 用户记录、位置、附件、封面、时光轴、回信 |
| `/api/tags/**` | 是 | 标签 |
| `/api/ai/**` | 是 | AI 辅助 |
| `/api/stage-summaries/**` | 是 | 阶段总结 |
