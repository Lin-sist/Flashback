# 《时光回序》页面状态与假数据说明（开发版 / P0）

## 0. 文档目的

本文档用于冻结《时光回序》首版前端开发中的：

* 页面默认状态
* 页面空状态
* 页面输入状态
* 页面状态切换规则
* 假数据字段结构
* 页面 mock 数据组织方式

适用范围：

* Uniapp + Vue 3 页面骨架开发
* Copilot 假数据生成
* Codex 状态流 review
* 接口联调前的本地模拟开发

## 1. 全局状态模型

## 1.1 信件状态枚举

```ts
export type LetterStatus = 'draft' | 'sealed' | 'unlocked'
```

说明：

* `draft`：草稿，可继续编辑
* `sealed`：已封存，未解锁
* `unlocked`：已解锁，可阅读并回应

---

## 1.2 页面来源枚举

```ts
export type PageSource = 'home' | 'archive' | 'timeline'
```

说明：
用于新建页、解锁页退出时判断返回来源。

---

## 1.3 首版统一数据主键

```ts
export type ID = string
```

建议：

* 前端 mock 阶段统一使用字符串 id
* 例如：`letter_001`、`timeline_003`

---

## 1.4 首版统一时间字段策略

首版前端建议同时保留三类时间字段：

```ts
createdAt: string      // 原始时间，ISO 字符串
updatedAt?: string     // 最近更新时间
displayTimeText: string // 页面展示用文案，如“3天前”“2024.10.21”
```

说明：

* 页面显示优先使用 `displayTimeText`
* 排序逻辑优先使用 `createdAt / updatedAt`

## 3. 首页状态与假数据说明

## 3.1 页面目标

首页是一级入口页，用于展示：

* 草稿入口
* 封存摘要
* 最近解锁摘要
* 我的档案入口
* 新建入口

## 3.2 页面状态

### 默认态

必须具备：

* 草稿入口卡
* 两张摘要卡
* 我的档案入口
* 底景图
* 悬浮 `+`

### 空态

当用户暂无记录时：

* 仍保留首页 Hero 标题与整体展陈结构
* 草稿入口卡可显示引导性占位文案
* 封存 / 最近解锁卡可显示空值或弱提示

### 滚动态

* 页面允许纵向滚动
* 不改变首页入口页属性

## 5. 新建页状态与假数据说明

## 5.1 页面目标

承载：

* 新建信件
* 编辑草稿
* 关闭时自动保存草稿
* 封存操作入口

## 5.2 页面模式

### 新建模式

从首页 `+` 进入
特点：

* 内容可能为空
* 页面处于初始书写态

### 编辑模式

从首页草稿卡 / 我的档案草稿条目 / 时间轴草稿节点进入
特点：

* 自动回填已有草稿内容
* 页面沿用新建页视觉形态

---

## 5.3 页面状态

### 默认态

* 显示占位文案
* 显示 `Vol.`、日期标题、纸张、底部三枚轻量入口、封存按钮

### 输入态

* 正文已输入
* 键盘弹起
* 输入区保持可视

### 自动保存态

* 点击 X 关闭时必须保存草稿

### 封存态

* 点击“封存这一刻”后进入封存流程

## 10. 页面状态切换规则

## 10.1 草稿相关

* 首页草稿卡点击 -> 新建页编辑模式
* 我的档案草稿条目点击 -> 新建页编辑模式
* 时间轴草稿节点点击 -> 新建页编辑模式

## 10.2 封存相关

* 首页封存总数卡点击 -> 轻提示
* 我的档案已封存条目点击 -> 轻提示
* 时间轴已封存节点点击 -> 轻提示

## 10.3 解锁相关

* 首页最近解锁卡点击 -> 解锁页
* 我的档案已解锁条目点击 -> 解锁页
* 时间轴已解锁节点点击 -> 解锁页

## 10.4 返回相关

* 新建页 / 解锁页都按 `source` 返回来源页面
* 新建页点击 X 必须自动保存草稿
* 解锁页点击“留下回应”首版只提示成功，不自动返回

---

## 11. 首版必须冻结的页面状态规则

以下规则进入 P0 后不要随意改动：

1. 首页必须同时承载草稿入口、封存摘要、最近解锁摘要、我的档案入口、新建入口
2. 我的档案必须支持 4 个筛选态：全部 / 草稿 / 已封存 / 已解锁
3. 新建页必须区分 `create` 和 `edit` 两种模式
4. 新建页点击 X 必须自动保存草稿
5. 解锁页必须包含顶部元信息、正文、回应输入、回应按钮
6. 时间轴节点必须按状态分流
7. 个人中心必须包含资料、统计、设置分组、退出入口
8. 首版所有页面都必须先有可用 mock 数据，不能等接口后再补页面壳子

## 12. 给 Copilot 的实现备注

Copilot 生成页面时应优先：

* 先根据本文件建立 mock 数据文件
* 再根据 mock 数据驱动页面骨架
* 页面组件 props 优先对齐这里的字段名
* 不要在多个页面里散写不同版本的同类字段
* `draft / sealed / unlocked` 的状态枚举必须统一

建议目录：

```text
src/
  mock/
    home.ts
    archive.ts
    compose.ts
    unlock.ts
    timeline.ts
    profile.ts
```
