## 6. 关键业务流程图

### 6.1 记录生命周期

```mermaid
stateDiagram-v2
    [*] --> DRAFT: 创建草稿
    DRAFT --> DRAFT: 编辑正文/标签/位置/附件/封面
    DRAFT --> SEALED: 交给时间
    SEALED --> UNLOCKED: 定时任务到期解锁
    UNLOCKED --> UNLOCKED: 查看时间回看/填写后来其实/可选回信

    note right of SEALED
      封存后正文、位置、附件、封面不可变
    end note
    note right of UNLOCKED
      解锁后仍保持封存内容不可变
      仅保留 M3 已接受的 later reflection / reply 行为
    end note
```

### 6.2 创建草稿并封存

```mermaid
sequenceDiagram
    participant U as 用户
    participant MP as 微信小程序
    participant API as RecordController
    participant S as RecordService
    participant DB as MySQL
    participant WX as 微信订阅消息

    U->>MP: 输入正文、标签、解锁时间
    MP->>API: POST /api/records
    API->>S: createDraft(user, request)
    S->>DB: 写入 record / record_tag
    DB-->>S: recordId
    S-->>API: RecordDetailVO
    API-->>MP: ApiResponse<RecordDetailVO>

    U->>MP: 点击交给时间
    MP->>API: POST /api/records/{id}/seal
    API->>S: sealRecord(user, id)
    S->>DB: status=DRAFT -> SEALED, sealed_at
    S-->>API: RecordDetailVO
    API-->>MP: 封存成功
    MP->>WX: requestSubscribeMessage(可选)
```

### 6.4 附件上传与封面选择流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant MP as 小程序记录编辑页
    participant API as AttachmentController
    participant S as RecordAttachmentService
    participant OS as ObjectStorageProvider
    participant OBJ as 私有对象存储
    participant DB as record_attachment

    U->>MP: 选择图片或录制语音
    MP->>API: POST /api/records/{recordId}/attachments/upload-token
    API->>S: createUploadToken(user, recordId, request)
    S->>S: 校验 owner / DRAFT / 类型 / 数量 / 大小
    S->>OS: createUploadAuthorization()
    OS-->>S: uploadUrl + headers/formData + key
    S-->>API: AttachmentUploadTokenVO
    API-->>MP: 上传授权
    MP->>OBJ: 直传文件
    OBJ-->>MP: 上传成功
    MP->>API: POST /api/records/{recordId}/attachments/commit
    API->>S: commitAttachment()
    S->>OS: getMetadata(key)
    OS->>OBJ: HEAD/stat
    OBJ-->>OS: metadata
    S->>DB: 校验后写入 AVAILABLE 附件
    S-->>API: RecordAttachmentVO
    API-->>MP: 可预览/播放
```

```mermaid
sequenceDiagram
```

### 6.5 AI 辅助流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant MP as 小程序
    participant API as AiController
    participant S as AiService
    participant P as AI Provider

    U->>MP: 请求写作提示或内容整理
    MP->>API: POST /api/ai/writing-prompts 或 summarize-record
    API->>S: generate(...)
    alt provider 已配置且返回正常
        S->>P: OpenAI-compatible chat completion
        P-->>S: 模型结果
        S-->>API: status=SUCCESS, source=deepseek/openai-compatible
    else provider 缺失/超时/响应异常
        S-->>API: status=UNAVAILABLE 或 FAILED
    end
    API-->>MP: 显式成功或失败状态
```

### 6.6 时光轴筛选与分页

```mermaid
sequenceDiagram
    participant U as 用户
    participant MP as Timeline 页面
    participant API as RecordController
    participant S as RecordService
    participant DB as MySQL

    U->>MP: 选择单个标签和/或年月日
    MP->>API: GET /api/records/timeline?tagId=&year=&month=&day=&pageNum=1&pageSize=20
    API->>S: getTimeline(user, query)
    S->>S: 校验日期依赖，按 Asia/Shanghai 生成 createdAt 区间
    S->>DB: 按 owner + tag + created_at range 查询，created_at DESC,id DESC
    DB-->>S: 当前页记录 + total
    S-->>API: TimelinePageVO(groups,total,pageNum,pageSize,hasMore)
    API-->>MP: 替换第一页数据
    U->>MP: 上拉加载更多
    MP->>API: GET /api/records/timeline?...&pageNum=2
    API-->>MP: 后续页，按 yearMonth 合并并按 recordId 去重
```
