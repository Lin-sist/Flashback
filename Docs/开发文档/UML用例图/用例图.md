# 时光回序 UML 用例图源码包（可本地导出 PNG）

这份文档提供 **PlantUML 标准用例图源码**。
如果聊天里的下载链接失效，你可以直接把下面代码复制到本地 `.puml` 文件，再批量导出成 PNG。

## 推荐本地导出方式

### 方式一：VS Code 插件

1. 安装 **PlantUML** 插件
2. 安装 **Java**
3. 将下面代码分别保存为 `.puml`
4. 在 VS Code 中打开文件，右键 **Preview Current Diagram** 或 **Export Current Diagram**

### 方式二：命令行批量导出

1. 准备 `plantuml.jar`
2. 安装 Java
3. 在文件夹下执行：

```powershell
java -jar plantuml.jar *.puml -tpng
```

## 1. 项目总体用例图

保存为：`01_项目总体用例图.puml`

```plantuml
@startuml
left to right direction
skinparam packageStyle rectangle
skinparam shadowing false
skinparam handwritten false
skinparam actorStyle stickman

actor "普通用户" as User
actor "管理员" as Admin
actor "定时任务" as Scheduler
actor "AI服务" as AI
actor "微信消息服务" as WX

rectangle "时光回序系统" {
  usecase "注册" as UC_Register
  usecase "登录" as UC_Login
  usecase "获取当前用户信息" as UC_GetUser
  usecase "修改个人资料" as UC_UpdateProfile

  usecase "创建草稿" as UC_CreateDraft
  usecase "编辑草稿" as UC_EditDraft
  usecase "删除草稿" as UC_DeleteDraft
  usecase "封存记录" as UC_SealRecord
  usecase "我的记录列表" as UC_RecordList
  usecase "记录详情" as UC_RecordDetail

  usecase "设置解锁时间" as UC_SetUnlockTime
  usecase "自动解锁到期记录" as UC_AutoUnlock
  usecase "发送解锁提醒" as UC_SendUnlockNotice
  usecase "查看已解锁记录" as UC_ViewUnlockedList

  usecase "查看已解锁记录详情" as UC_ViewUnlockedDetail
  usecase "查看当时元信息" as UC_ViewMeta
  usecase "进行当时与现在对照" as UC_ComparePastNow

  usecase "创建回信" as UC_CreateReply
  usecase "查询回信" as UC_QueryReply

  usecase "查询标签列表" as UC_QueryTags
  usecase "记录绑定标签" as UC_BindTags

  usecase "获取写作提示" as UC_GetPrompts
  usecase "整理记录内容" as UC_SummarizeContent

  usecase "管理员登录" as UC_AdminLogin
  usecase "用户列表查询" as UC_AdminUsers
  usecase "记录列表查询" as UC_AdminRecords
  usecase "标签列表查询" as UC_AdminTags
  usecase "新增标签" as UC_AddTag
  usecase "修改标签" as UC_EditTag
}

User --> UC_Register
User --> UC_Login
User --> UC_GetUser
User --> UC_UpdateProfile
User --> UC_CreateDraft
User --> UC_EditDraft
User --> UC_DeleteDraft
User --> UC_SealRecord
User --> UC_RecordList
User --> UC_RecordDetail
User --> UC_ViewUnlockedList
User --> UC_ViewUnlockedDetail
User --> UC_ViewMeta
User --> UC_ComparePastNow
User --> UC_CreateReply
User --> UC_QueryReply
User --> UC_QueryTags
User --> UC_BindTags
User --> UC_GetPrompts
User --> UC_SummarizeContent

Admin --> UC_AdminLogin
Admin --> UC_AdminUsers
Admin --> UC_AdminRecords
Admin --> UC_AdminTags
Admin --> UC_AddTag
Admin --> UC_EditTag

Scheduler --> UC_AutoUnlock
WX --> UC_SendUnlockNotice
AI --> UC_GetPrompts
AI --> UC_SummarizeContent

UC_SealRecord ..> UC_SetUnlockTime : <<include>>
UC_CreateDraft ..> UC_BindTags : <<include>>
UC_EditDraft ..> UC_BindTags : <<include>>
UC_ViewUnlockedDetail ..> UC_ViewMeta : <<include>>
UC_ViewUnlockedDetail ..> UC_ComparePastNow : <<include>>
UC_CreateReply ..> UC_ViewUnlockedDetail : <<extend>>
UC_AutoUnlock ..> UC_SendUnlockNotice : <<extend>>
@enduml
```

## 10. 可选：批量渲染脚本

保存为：`render_all.ps1`

```powershell
$jar = ".\plantuml.jar"
Get-ChildItem -Filter *.puml | ForEach-Object {
    java -jar $jar $_.Name -tpng
}
Write-Host "全部 PNG 导出完成"
```
