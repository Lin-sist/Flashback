## 2. 当前可用能力快照
- 用户侧认证：注册、登录、获取当前用户、更新个人信息。
- 记录主链路：草稿管理、封存、列表与详情、已解锁列表。
- 回信能力：仅已解锁记录可回信，单记录仅一条。
- 标签与时间轴：标签查询、记录标签绑定、按年份/标签筛选。
- 解锁任务：到期解锁 + 解锁日志落库 + 幂等约束。
- AI 最小能力：写作提示、内容整理、异常/超时兜底（mock/provider fallback）。
