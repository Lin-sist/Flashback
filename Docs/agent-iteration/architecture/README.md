## 本目录解决什么问题

蓝图管「往哪走、什么顺序」，OpenSpec change 管「这一刀做什么、怎么验收」。两者中间缺一层：
**哪些分层与端口必须长期守住，才能在换检索引擎 / 换 provider / 换评测方案时不推倒 Runtime。**
本目录补这一层：

1. **架构宪法**：逻辑分层、六大稳定端口、Loop 不变式、反推倒底线
2. **技术选型草稿**：已落地事实 + ADR 式推荐 + 明确不选 + 实现漂移登记
