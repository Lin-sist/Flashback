## 1. 记录规则

- 参与者只使用 `P01`～`P08`；不记录姓名、联系方式、账号、公司或其他身份线索；
- 不记录正文、标题、地点、文件名、图片内容、声音内容或真实 Agent 对话；
- `yes / no / uncertain / blocked / invalid` 必须来自实际观察，未知就留空；
- 主持人解释正确路径后，该轮标记 `invalid`，不计入聚合；
- 原型故障导致无法完成时标记 `blocked`，不把它推断为用户误解；
- 参与者自己的说法只写不含私人内容的短摘要，不复制敏感原话。
