# Flashback 前端视觉语言演进计划

> 状态：Gate 1 规划草案。本文不是已选定视觉规范，也不授权修改业务代码。

## 目标

在不改变 Flashback 产品初心、导航和真实业务契约的前提下，探索更有辨识度的视觉语言与动效。最终只选择一套主方向，渐进迁移现有前端。

## 为什么不直接继续 M1

既有 M1 的任务是把 `Docs/design/home-v2/` 的宣纸朱砂 HTML 高保真转译为小程序，并禁止替代风格。本轮要比较多套风格，目标与 M1 不同，因此使用新的 `frontend-visual-language-evolution` change；M1 保留为历史与未完成验收事实。

## 探索范围

四套候选：

1. 纸上留白：现有方向的现代化、减装饰版本。
2. 私人馆藏：现代博物馆/编辑索引式私人档案。
3. 生命剪贴：以真实照片、声音和时间票据为主角的受控拼贴。
4. 暮色回声：用于时间回看语境的低亮度、电影感时间层次。

共同页面：

- 首页
- 记录编辑器
- 时光轴

共同状态：短文字、图片、声音、SEALED、UNLOCKED、时间篇章、加载、空、失败、Preview。

## 工作流

```text
公开案例研究
  → 四方向 brief
  → 同内容/同屏幕原型
  → 产品与技术评审
  → 锁定一套主方向
  → Gate 1 批准

  → 共享 token/组件
  → 分批迁移与验收
```

## 评审门槛

- 首页是否仍把“留下此刻”作为唯一主动作？
- 一句话、一张图片或一段声音能否独立成立？
- 是否像私人生命片段空间，而不是管理台、作品集或 AI 聊天？
- 动画关闭后是否仍完整可用？
- 是否能在微信小程序稳定降级？
- 是否保留三个一级 Tab、canonical naming、Preview fail-closed？
- 是否只使用合成内容进行外部设计？
