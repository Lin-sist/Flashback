# 候选视觉方向

## A｜纸上留白

关键词：温暖纸白、现代宋体、深墨、单点朱砂、大留白、安静确认。

- 首页：主问题和输入动作占据视觉中心，未来抵达信息退到下方。
- 编辑器：无边框写作面，媒体和见证者入口退居边缘。
- 时光轴：轻量时间脊柱、低对比日期、片段式排版。
- 动效：墨迹揭示、细线落印、纸面轻抬。
- 禁止：折角/印章/纸纹同时堆叠，古风书法化，满屏慢入场。

## B｜私人馆藏

关键词：骨白、黑墨、编号、日期索引、编辑网格、馆藏标签。

- 首页：一句品牌承诺＋明确记录动作，最近片段呈馆藏索引。
- 编辑器：标题/日期/正文像编辑稿页，功能区极简。
- 时光轴：年份/月/日形成固定索引列，篇章是章节页。
- 动效：索引展开、图像遮罩、日期列推进、内容重排。
- 禁止：冷冰冰的资产管理台、大量统计、把用户称为“藏品”。

## C｜生命剪贴

关键词：照片、声音、票据、轻错层、非规则网格、真实现场。

- 首页：有媒体时由最近一段真实媒体形成视觉锚点；无媒体时排版完整成立。
- 编辑器：附件像放入桌面的素材，但正文仍是主输入。
- 时光轴：文字/图片/声音使用不同节奏，不成为瀑布流社交 feed。
- 动效：照片轻错层、卡片堆叠、附件柔和展开、片段交叉淡化。
- 禁止：自动生成装饰照片、胶带贴纸泛滥、信息密度失控。

## D｜暮色回声

关键词：深墨、暖灰、低亮照片、时间光点、远近层次、静夜阅读。

- 首页：写作区保持明晰，不用深色效果制造压迫。
- 编辑器：可采用局部夜间写作语言，但长文对比度优先。
- 时光轴/时间回看：由远到近聚焦相关片段，突出过去与现在的边界。
- 动效：暗到明显现、时间点聚焦、图像缓慢显影。
- 禁止：悲情滤镜、电影预告片感、把普通生活宏大化、持续光点动画。

## 选择方式

四套方向不是投票选“最漂亮”，而是按产品气质、表达清晰、阅读无障碍、微信可行性和辨识度共同评审。任何破坏真实性、主路径或隐私边界的方向直接淘汰。
