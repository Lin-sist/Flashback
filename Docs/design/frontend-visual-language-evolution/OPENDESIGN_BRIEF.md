## 1. Product

Flashback 是私人生命片段记录空间。用户可以只留下一句话、一张图片或一段原始声音，一条很短的表达已完整成立。AI 不是主角，只在用户主动邀请时作为有朋友温度的见证者。首页核心承诺是"给想留下的此刻，一个位置"。

## 2. 方向与材质故事

**主方向（工作名「信笺」）**：书写与回看共用同一种书信质感——用户写下的是一封信，封存的是一封信，未来读到的是一封信。档案馆是空间隐喻（存档编号、印章、保管），但一切语汇以"信"优先、"档案"为辅，禁止台账感与资产管理腔。

三句材质故事，所有设计决定向它们对齐：

1. **纸是世界的材质**。页面、卡片、书信都是纸；纸恒常、温暖、等着接住此刻。
2. **玻璃是动作与暂时之物的材质**。按钮、浮层、Tab 这些"当下正在发生"的元素允许微液态玻璃；玻璃永远不承载内容本体。
3. **霜是被封存时间的材质**。封存/未解锁的内容被霜遮住；抵达时霜融。

对 v2 气质底线的继承与修订：

- 继承：首页是"位置/房间"不是"出版物/杂志"（3 秒检验保留）；"留下此刻"是第一入口与视觉重心；最近片段被安放不被展出；系统声音最小化；低门槛表达；安静纸张底色；朱砂只服务动作、时间与信任符号。
- **修订（取代 v2 §2.4）**：时间语法统一为"抵达"——未来以"等待/即将抵达"的温暖语法出现，禁止"落后/欠账/连续天数/缺失日期"的焦虑语法。首页以"现在"为主时态，允许一句"等待被未来的你重新读懂"式的未来低语（2.0 现状保留）。
- v2 §3 失败教训继续有效：出版物家具不得出现在首页；层级不得倒置（动作先于已保存内容）；方向语汇不得漂移。

## 3. 玻璃剂量地图（硬约束）

| 位置 | 材质 | 备注 |
|---|---|---|
| 主动作按钮（留下这一刻、保存） | **玻璃药丸（全 app 最玻璃之物）** | 半透明磨砂＋高光描边＋按压厚度 |
| 门厅入口（提笔书写、进入档案馆） | 取景框标记＋极淡玻璃薄片 | 取景框＝位置语法，玻璃只做填充 |
| 底部 Tab 栏 | 轻玻璃 | 半透明＋背景模糊，内容从底下虚化穿过 |
| 浮层/弹层/筛选 chips | 轻玻璃 | 临时之物用临时之材 |
| 封存/未解锁卡 | 霜模糊 | 语义性：封印未解的状态本体，非装饰 |
| 时刻卡片/信卡正文/书写页 | **纸，禁玻璃** | 卡片是装裱；仅书写页底部动作条可用玻璃 |
| 首页书写空位 | 纸 | 聚焦微浮起，像揭开封口 |

- **动作语法分工**：药丸＝动作（保存类）；取景框＝位置（入口类）。两套语法不合并、不混用。
- 深色模式：本轮不做。玻璃在深色下是另一套物理。
- 微信实现风险与降级：玻璃以 `backdrop-filter` 实现，Skyline 渲染器不支持、Android WebView 支持不一——**每个玻璃元素必须声明"暖纸实色"降级态**；玻璃只用于小面积元素，禁全屏实时模糊。

## 4. 信笺家具规范（已裁决，不得增删）

1. **红圆印（封／阅）**：留，升格为系统符号——"封"属封存与保存（落印），"阅"属阅读态。
2. **折角**：留，但只允许出现在"信"（内容卡、书信页、已保存卡）；面板、工具、表单区禁用。
3. **存档编号**：留，统一汉字间隔式（存档第 三〇 号）；只出现在回看详情与封存详情；首页与列表页禁用。
4. **封存倒计时**：改静态期待——大字只到"天＋时"或日期式（如"即将抵达 · 2027 年夏"）；**禁秒级跳动**。
5. **"MEMORY"类英文小字标签**：删除。全系统禁装饰性英文元数据；卡片质感靠照片与排版承担。
6. **竖排侧注**：留形式，文案软化为低语式（如"只写给自己"），朱砂色保留。
7. **"预计 X 年解锁"**：留。全系统时间语法＝抵达，不是欠账。

「时刻卡片」继续作为全局组件（继承 v2 §11.2）：照片＋片段文字＋可选波形条；状态一律小药丸；无黑底说明条、无编号；卡片只是装裱，不携带藏品语义。

## 5. 动效规范（仅此四枚签名，其余安静）

1. **落印（保存）**：保存成功后当前页信卡化，红印"封"落于卡片右下——一次下压、微微晕开，配"这一刻已经留下"；默认无声音、不自动跳转；触感可选；reduced-motion 时印章直接显示。
2. **融霜（抵达）**：封存信解锁时，霜从卡片边缘退去、内容显影；一次性，非循环；reduced-motion 时直接显示解锁态。
3. **脊线生长＋节点点亮（时光轴）**：进入时脊线自上而下生长；节点过视口中线点亮，最多两态（空心＝纯文字、实心＝含媒体）。
4. **卡片轻浮进入**：卡片随滚动一次性轻浮进入；禁视差堆叠、滚动劫持、循环动画。

全部动效必须提供 reduced-motion / 静态降级。

## 6. 逐屏要求

### 6.1 首页（融合结构：2.0 叙事＋空位本体）

- 保留 2.0 叙事骨架：顶部"时 光 回 序"字标、问候句"今天的你，想留下些什么？"、副句"你写下的此一刻，正等待被未来的你重新读懂"、未来信件引导卡、最近抵达卡。
- "提笔书写"升级为**取景框空位**：四角取景标记保留，框内为比纸面深半档、微微凹陷的安静面板，placeholder"此刻，你想留下什么？"以正文色（非灰）坐在其中；点击进入书写页，首页不直接输入。
- 未来信件卡与最近抵达卡＝安放层级：信卡质感（可折角）、柔影浮起；不编号、不解释、不黑底说明条。
- 首页禁：档案编号、功能名"我的记录"、统计数字、出版物家具。

### 6.2 书写页（信笺）

- 第一屏只有：日期抬头（记录于 二零二六年·暮秋）、正文（宋体、无边框）、附件区、底部三键（地点/图片/语音）＋玻璃药丸"留下这一刻"。
- 记录类型（此刻/写给未来/人生节点/情绪片段）、"选择这次怎么聊"、"你当时以为＋AI 整理"收进可展开的**"附言（可选）"区**：默认收起，默认类型"此刻"。
- 竖排侧注保留（文案按 §4.6）。红印不在本页出现（印属于封存与保存）。

### 6.3 已保存页（现"草稿页"，重做）

- 白卡浮灰底 → **信卡化**：信纸质地＋折角，含正文、留下时间，"继续补充"为文字链接；落印动效发生在本页（§5.1）。
- Agent 参考开关区（不再供参考／只代表当时，不代表现在）排印安静化，收在次级。

### 6.4 时光轴

- 保留 2.0 结构：页头"时间长廊"＋副句、轻脊柱＋节点、条目按内容形态区分（文字＝排印块、图片＝时刻卡、声音＝波形卡、篇章＝章节板，禁全部卡片化）。
- 动效按 §5.3/§5.4；筛选 chip 按轻玻璃。

### 6.5 回看详情（信阅读态）

- 保留信纸结构：存档编号＋地点行、季节字、红印"阅"＋"过去的你"、正文信卡、当时所在、当时留下的片段（图片网格＋封面标记）。
- "现在的我·后来其实"回应区做成**回信形态**（小信纸卡）；"和它聊聊那时候"保持文字链接；Agent 参考开关安静化。

### 6.6 封存页

- 霜卡：正文被霜遮住、边缘结霜更重、标题微透；红印"封"。
- 倒计时按 §4.4 静态期待；"解锁后，过去的你会读到这封信"保留；融霜动效预留（§5.2）。

### 6.7 档案页（我的记录）

- 结构保留：搜索、状态筛选 chips、档案概览、卡列表（信封/锁图标＋状态药丸＋"预计 X 年解锁"）。
- 卡片统一信卡质感；计数以保管事实语气呈现（"共 18 份记录"）；列表行不出现编号。

### 6.8 个人中心（保管室门厅，重设计）

- 三区结构：
  1. **身份与保管陈述**——真实微信头像＋昵称＋一句保管事实："这里替你保管着 14 封信，还有 0 封在路上。"（数字并进一句话，不立统计卡）。
  2. **记录与时间**——我的记录、时间回看、"整理成一封近况"（原"阶段总结·生成"换信笺动词，降为安静入口卡）。
  3. **数据与信任**——**托管凭证卡**独占全页唯一的视觉突出（导出与清理是它的动作），配一枚"守"字小印；"关于"收尾。
- 禁：统计数字卡、进度条、活跃语言、iOS 设置皮肤、裸标题＋箭头列表。

### 6.9 登录页（微调）

- "久违了，时间的旅人""在此处，开启你的私人档案馆""进入档案馆"已成立；只做材质与字距微调；"进入档案馆"为取景框＋极淡玻璃填充。

## 7. 材质细则（吸收 v2 §12–§13 仍有效部分）

- **纸底**：保留 2.0 暖米白＋晕影；允许 ≤3% 明度晕影渐变，禁重复纹理图案（低端机摩尔纹风险）。surface 比纸底浅半档，凹陷面板/书写位深半档——"东西放在纸上"必须摸得到。
- **字**：display＝宋体系（日期抬头、问候句、信笺正文），body＝PingFang；大/中/小三档保持强对比（"一个大、多个小"），meta 层 11px；禁 13/14/15 挤成均匀一片。
- **影**：信卡 10–14% 柔影真正浮起；辅助面板走描边扁平；禁 4–6% 脏平中间态。
- **照片**：全色彩还原，全系统禁压灰滤镜；照片是纸面上唯一的色彩生命来源。
- **网格**：8pt 对齐；组内 8–12px、组间 28–36px、区块前更大；禁全页单一步距。
- **朱砂点位**：留下这一刻/保存、落印、时光轴点亮节点、Tab 激活态、托管凭证"守"印；同一屏幕红色不超过三处。

## 8. 命名与合规

- 一级 Tab：首页、时光轴、**个人中心**（现行"我的"按仓库规范恢复全名）。
- 用户可见命名不变：我的记录、时光轴、时间回看。
- 首页顶部仅"时 光 回 序"字标；功能名不进首页头部。
- 主路径：留下此刻 → 保存 → 结束；Agent、封存、时间回看、时间篇章均为次级/主动选择。

## 9. Avoid（继承并追加）

- 继承 v2 §9：日记 App 模板感、效率 dashboard、社交 feed、AI chat 首页；古风书法、装饰印章泛滥、怀旧滤镜堆叠；未来焦虑、宏大人生叙事、心理诊断或情绪评分；出版物骨架（报头、刊号、页码、INDEX）作为页面通用骨架；满页横贯分隔线；连续天数与缺失日期；把"留下此刻"降级为次要按钮。
- 追加：全盘液态玻璃；玻璃承载内容正文；秒级跳动倒计时；深色模式（本轮）；装饰性英文元数据；台账感档案语言；把个人中心做成统计面板。

## 10. Artifact 与交付

- **单方向原型五帧**：首页、书写页、时光轴、回看/封存详情、个人中心。
- **三张材质放大稿**：①玻璃药丸＋取景框空位；②霜封卡（融霜前后两态）；③落印瞬间。
- **两项动效说明**（落印、融霜）＋全部动效的 reduced-motion 降级说明。
- 每帧附自检：玻璃剂量对照 §3、信笺家具对照 §4、时间语法对照 §2（"抵达"而非"欠账"）。

## 11. 合成内容

- 短文字："傍晚下过一阵雨，窗边的风有一点凉。"
- 图片：抽象的雨后窗面/街灯占位图，不使用真实人物。
- 声音：`00:18 原始声音` 结构化占位。
- 状态：一条已留下、一条封存中（含解锁日期）、一条已抵达、一个合成时间篇章。
- 保管事实示例："这里替你保管着 14 封信，还有 0 封在路上。"
- 封存卡正文一律使用合成长文；**不得复述 `2.0页面效果/` 截图中的任何真实文字**。
