# E1 时间篇章产品负责人假设

> 状态：`CONFIRMED BY PRODUCT OWNER / UNVALIDATED BY PARTICIPANTS`
> 日期：2026-08-28
> 证据边界：以下内容来自产品负责人盘问确认，用于约束原型；不构成目标用户正证据，不授权 P5.x

## 1. 核心价值与进入时机

- **D1**：篇章提供的不可替代价值不是整理效率，而是用户自己命名、可结束、可重新打开且不评价成败的“尚未结束生活容器”。
- **D2**：片段始终先独立保存；保存过程中不询问、不推荐、不要求选择篇章。
- **D3**：第一版只能从至少一条已保存片段创建篇章，不允许预先创建空篇章。
- **D4**：创建后，未来片段仍须在保存完成后由用户主动加入；不自动吸附，不在保存成功后弹出提示。

## 2. 成员关系

- **D5**：第一版每条片段属于零个或一个主篇章；多篇章归属只作为未来候选，不预埋承诺。
- **D6**：可加入状态为 SAVED、SEALED、UNLOCKED；技术 DRAFT 不可加入、不可计数、不可用于创建。
- **D7**：SEALED / UNLOCKED 的篇章归属可由用户修改，因为它是外部关系；不得借此修改正文、位置、附件、封面或时间属性。
- **D8**：片段已有归属时，加入另一篇章必须明确称为“转移”，显示原篇章和目标篇章，确认后才执行。
- **D9**：批量操作显示新增与转移数量，并采用全部成功或全部保持原状的语义。
- **D10**：重复加入幂等；并发冲突不静默覆盖，须返回最新真实归属。

## 3. 生命周期

- **D11**：第一版仅有“进行中 / 已结束”两种用户可见状态，允许同时存在多个进行中篇章。
- **D12**：结束只表示用户认为这段生活暂时告一段落；不评价结果，不封存片段，不触发 Agent。
- **D13**：已结束篇章不能直接加入新片段，必须先重新打开；仍允许移出或转走成员以纠正归属。
- **D14**：重新打开原篇章，不复制、不拆分；第一版不展示多次结束—重开的生命周期历史。
- **D15**：系统永不自动结束，不按日期、沉默时长、成员数量或 AI 判断结束，也不提供预定结束。
- **D16**：创建时禁止空篇章；成员删除或转移导致的被动空篇章必须保留，允许以后加入或主动删除。

## 4. 时间与呈现

- **D17**：第一版不要求填写主观开始/结束日期。
- **D18**：系统只记录创建时间、当前结束操作时间和成员片段覆盖范围；界面必须写“片段覆盖时间”，不得冒充生活阶段的真实起止。
- **D19**：篇章详情按片段原有时间排序，可切换正序/倒序；第一版不支持拖拽编排。
- **D20**：不新增第四个一级 Tab；“我的记录”内提供“记录 / 篇章”二级切换。
- **D21**：用户从一条或多条完整记录发起“组成篇章”；单条详情提供次级“加入 / 移出 / 转移篇章”。
- **D22**：篇章卡只显示名称、状态、片段数量、明确标注的片段覆盖时间和可选自述摘要；无封面、进度、结果或 AI 摘要。
- **D23**：列表按“进行中 / 已结束”分组，进行中优先；组内暂按最近成员片段时间排序，空篇章回退到最近更新时间。该排序仍属原型待观察细节。

## 5. 用户内容

- **D24**：篇章名称必填，自述可选；自述只表达“这段生活对我是什么”。
- **D25**：名称和自述在进行中、已结束状态均可修改，不回写成员片段。
- **D26**：名称不要求唯一；内部 ID 区分，同名篇章通过状态、覆盖时间和自述辨认。
- **D27**：名称去除首尾空白，自述可空，拒绝控制字符；具体长度留给 P5.x 按现有契约统一决定。

## 6. 删除与数据权利

- **D28**：删除篇章只删除容器和归属关系，所有片段保留并恢复为无篇章；确认前显示成员数量和“只删除篇章，不删除记录”。
- **D29**：进行中篇章也可直接删除，不强迫先结束。
- **D30**：删除单条记录同步移除关系并重算数量和覆盖时间，不自动删除篇章。
- **D31**：全量导出未来应包含篇章元数据和成员关系，但不复制片段正文；全量清除/账号删除应覆盖篇章与关系。

## 7. 隔离、隐私与非目标

- **D32**：第一版篇章与 Agent 完全解耦，不总结、不命名、不推荐、不自动归入。
- **D33**：标签与篇章独立共存，不互相转换；名称/自述可作为未来搜索字段，片段正文不用于推断篇章。
- **D34**：Preview 只可展示固定合成篇章；全部 mutation fail-closed，不请求真实 backend。
- **D35**：所有操作 owner-scoped；日志只记录结构化 ID、状态、数量和结果，不记录名称、自述或片段内容。
- **D36**：第一版排除多篇章、子篇章、拖拽叙事、自动封面、目标/进度/提醒、分享协作、自动结束、阶段预测、人生诊断和新一级 Tab。
