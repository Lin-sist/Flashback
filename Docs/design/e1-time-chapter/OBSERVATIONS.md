## 1. 记录规则

- 未观察到的字段必须留空，不得根据产品负责人意见或内部走查补值；
- `yes / no / uncertain / blocked / invalid` 只能来自实际观察；
- 不记录真实人生阶段、日记、标题、地点、图片、声音、账号或身份；
- 主持人泄露正确模型记 `invalid`，原型故障阻断任务记 `blocked`；
- 只有 `valid` 场次进入聚合。
