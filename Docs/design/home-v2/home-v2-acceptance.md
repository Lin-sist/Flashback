# 《时光回序》首页 v2 验收标准

## 1. 验收目标

本次首页 v2 改造的验收目标是：

- 页面整体接近 `home-v2-reference.png`
- 首页信息结构清晰
- 用户一眼能理解：可以写下此刻，内容会被保存，之后可以查看不同状态
- 页面保持安静、克制、温柔、留白
- 不恢复旧版首页的复杂模块
- 不影响其他页面和真实业务逻辑

---

## 2. 文件范围验收

允许修改：

- 首页页面文件
- 首页样式文件
- 首页局部组件文件，如项目已有相关拆分
- 首页展示数据映射，如仅用于展示状态文本

不允许修改：

- 登录页
- 时间轴页
- 个人中心页
- 新建页
- 解锁详情页
- 我的档案页
- 后端代码
- 路由配置，除非首页原有跳转需要保持
- 全局样式大改
- 接口结构
- 数据库结构
- 无关依赖

验收时检查 Git diff，确认没有无关文件被改动。

---

## 3. 页面结构验收

首页必须包含以下结构，顺序不可乱：

1. 顶部品牌区
2. Hero 欢迎区
3. 主行动卡
4. 状态入口区
5. 底部 tab bar

不得新增：

- 最近动态列表
- 大图氛围区
- 浮动加号
- 多余统计卡
- 大面积装饰区
- 营销介绍区

---

## 4. 顶部品牌区验收

必须满足：

- 顶部只显示“时光回序”
- 品牌名居中
- 左右没有无功能图标
- 顶部不与微信状态栏、胶囊按钮、安全区冲突
- 顶部整体轻、简洁、安静

不通过情况：

- 出现菜单图标
- 出现搜索图标
- 品牌名偏移明显
- 顶部变成网页导航栏
- 顶部留白明显失衡

---

## 5. Hero 验收

必须显示：

```text
今天的你，
想留下些什么？
```

必须显示：

你写下的东西，会被好好保存。
后来的你，会有机会重新读懂它。

验收点：

主标题断行自然
不出现“么？”单独一行
不出现单字悬挂
主标题有中文标题气质
副文案清楚可读
Hero 与主卡之间留白自然
Hero 不像网页 banner 或宣传海报

## 6. 主行动卡验收

必须显示：

写下此刻

必须显示：

把今天的心情、困惑或期待，
先好好放在这里。

必须显示按钮：

开始书写

视觉验收：

主卡是首页视觉核心
主卡像一张被认真留出来的纸页
有轻微纸面感或柔和材质感
边框极轻
阴影柔和但有承托感
不像普通功能卡
不像 dashboard 卡片
不像营销 CTA 卡
不使用照片或插画
不出现强玻璃、强渐变、重纸纹、复古做旧

交互验收：

点击“开始书写”仍进入原有新建 / 写作页
不破坏已有跳转逻辑
不新增无关弹窗

## 7. 状态入口区验收

必须显示三项：

未写完
保存中
已抵达

必须显示对应数量，数量可使用真实数据或当前展示数据。

视觉验收：

三项在同一个统一容器中
不拆成三张独立卡
不变成 dashboard
数字是附属信息
图标统一
分隔线轻、短、柔和
模块不抢主卡注意力
但不能虚到不可读

交互验收：

点击对应状态时，若当前已有跳转逻辑，应保持原逻辑
若当前没有细分跳转，不得擅自新增复杂路由
可保留为进入档案 / 列表页的轻入口

## 8. 底部 tab bar 验收

必须满足：

保留首页、时间轴、我的 / 个人中心三个入口
当前页选中态清楚
不遮挡内容
真机底部安全区正常
不抢主视觉

## 9. 真机与开发者工具验收

必须完成：

运行小程序构建命令，例如：
pnpm dev:mp-weixin
微信开发者工具打开正确目录：
dist/dev/mp-weixin
截图首页，与 home-v2-reference.png 对比。

重点检查：

顶部安全区
Hero 断行
主卡比例
按钮位置
状态区可读性
底部 tab bar 安全区
不同屏幕高度下是否溢出
页面是否可以正常滚动或固定显示

## 10. 代码质量验收

必须满足：

无编译错误
无模板污染，如 </content>、</invoke>
无无关 console 噪音
无无关依赖
无后端改动
无路由破坏
无明显重复样式
样式命名清楚
若使用 token，应尽量复用现有全局色彩与间距变量

## 11. 最终验收判断

通过标准：

首页第一眼比旧版更简洁、更温柔、更清楚
用户能理解“写下此刻”的主动作
用户能理解内容有“未写完 / 保存中 / 已抵达”状态
页面接近参考图，不发生明显风格偏移
工程逻辑保持正常
其他页面未被影响

不通过标准：

页面变成 dashboard
页面变成普通日记首页
页面恢复旧版图片 / 大卡堆叠 / 浮动加号
主卡失去视觉核心地位
Hero 断行异常
状态区变成强统计模块
Codex 自行重新设计页面
