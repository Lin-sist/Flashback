# 《时光回序》首页 v2 视觉契约

## 1. 设计定位

首页 v2 的目标是替换当前首页视觉，形成一个更简洁、更温柔、更克制的首页入口。

首页不是功能面板、数据看板、营销页或普通日记首页。它应当像一个安静的时间前厅，让用户进入后自然理解：

- 我可以把此刻写下来；
- 我写下的东西会被好好保存；
- 后来的自己会有机会重新读懂它；
- 我的内容会处在“未写完 / 保存中 / 已抵达”等不同时间状态中。

核心气质：

- 安静
- 克制
- 温柔
- 留白
- 私密
- 轻仪式感
- 时间被妥善保存的感觉

核心理念：

> 你写下的东西，会被好好保存。  
> 后来的你，会有机会重新读懂它。

---

## 2. 改造边界

本次只改首页 UI，不改业务主链路。

允许修改：

- 首页 `pages/home/index` 相关结构与样式
- 首页局部 mock / preview 展示数据的文案映射，如有必要
- 首页相关的局部样式变量

禁止修改：

- 后端接口
- 登录逻辑
- 路由结构
- 底部 tab 页面数量
- 全局主题大改
- 其他页面视觉
- 数据库或 API 返回结构
- 新增无关组件库
- 新增大图、照片、复杂插画
- 恢复旧版首页的大图、浮动加号、统计卡片堆叠

---

## 3. 页面结构

首页 v2 固定为五段式结构：

1. 顶部品牌区
2. Hero 欢迎区
3. 主行动卡
4. 状态入口区
5. 底部 tab bar

不要新增新的内容区块。不要恢复“最近动态列表”“大图氛围区”“封存统计大卡”等旧结构。

---

## 4. 顶部品牌区

### 内容

只保留居中的品牌名：

- 时光回序

### 视觉要求

- 顶部只保留品牌名，不要左右功能图标。
- 品牌名居中，视觉稳定。
- 顶部区域保持极简、安静、克制。
- 顶部与 Hero 之间需要有充足留白。
- 不要做成网页导航栏。
- 不要新增搜索、菜单、设置等无功能入口。

### 验收点

- 顶部没有左图标。
- 顶部没有右图标。
- “时光回序”居中。
- 顶部看起来是有意设计的极简品牌栏，不是删掉图标后的空白。

---

## 5. Hero 欢迎区

### 文案

固定使用：

```text
今天的你，
想留下些什么？
```

说明文案固定使用：

你写下的东西，会被好好保存。
后来的你，会有机会重新读懂它。
视觉要求
主标题两行自然断句，不能出现单字或“么？”单独掉到下一行。
主标题可使用宋体 / serif 气质字体，保持文艺感，但不要过重。
主标题应像轻声提问，不像宣传海报。
说明文案居中，颜色低对比灰蓝，语气轻柔。
Hero 与主卡之间有自然呼吸感。
不要加入插画、图案、大背景或额外解释文案。
建议视觉参数

可根据项目实际单位调整：

Hero 顶部留白：较大，形成安静开场
标题字号：约 52–60rpx
标题行高：约 1.35–1.55
副文案字号：约 26–30rpx
副文案行高：约 1.7–1.9
副文案颜色：低饱和灰蓝，如 #7F8C93 附近

## 6. 主行动卡
内容

固定使用：

写下此刻

说明文案：

把今天的心情、困惑或期待，
先好好放在这里。

按钮：

开始书写
职责

主行动卡是首页最重要的视觉与功能核心。它不只是一个功能入口，而是一张“为此刻预留的纸页”。

它需要传达：

专属感：这是留给用户此刻的位置
托付感：用户可以把心情放在这里
郑重感：写下此刻是一件被认真对待的事
行动邀请感：用户自然愿意点击开始书写
视觉要求
主卡整体像一张安静放置的纸页。
大圆角白色卡片，极轻边框。
阴影柔和，不能强悬浮，但需要有承托感。
卡片应从背景中轻轻分离，不要像普通 UI 白卡。
卡片内部留白充足，但不能显得空洞。
标题、细分割线、说明文案、按钮之间的距离必须精细。
允许极轻纸面感、柔和白色层次、微妙边缘层次。
禁止明显纸纹、做旧、复古、强拟物、强玻璃、强渐变。
禁止加照片、大图、复杂插画。
主按钮为低饱和蓝灰色，宽度适中，非满宽按钮。
按钮像温柔明确的邀请，不像后台按钮或营销按钮。
建议视觉参数

可根据项目实际单位调整：

卡片左右边距：约 40–48rpx
卡片圆角：约 34–44rpx
卡片高度：保持当前大卡比例，不要压缩成普通小卡
边框：1rpx，极浅冷灰
阴影：低透明、柔和扩散，下方承托感
标题字号：约 40–46rpx
说明字号：约 26–30rpx
按钮高度：约 76–88rpx
按钮圆角：约 20–28rpx
按钮颜色：低饱和蓝灰，如 #6F8390 / #728895 附近

## 7. 状态入口区
内容

固定为三项：

未写完  2
保存中  1
已抵达  12

真实项目中数量可来自数据，展示时保持轻量。

职责

状态区不是强功能区，也不是 dashboard。它是“轻量时间归档摘要”。

它告诉用户：

你的内容没有散落；
它们被安放在不同时间状态中；
点进去可以查看具体内容。
视觉要求
保持横向三栏结构。
外层是一个统一容器，不要拆成三张独立卡。
容器轻、稳、完整，不抢主卡注意力。
图标统一线性风格，大小、粗细、视觉重心一致。
分隔线要短、淡、柔和，不像表格线。
数字是附属信息，不能成为统计重点。
数字不要像强通知角标。
文字“未写完 / 保存中 / 已抵达”比数字更重要。
可保留极淡点状纹理，但如果影响干净感，可弱化或移除。
整体感觉应像“归档摘要”，不应像后台统计卡或功能菜单。
建议视觉参数
容器左右边距：与主卡大致对齐
容器圆角：约 28–36rpx
容器高度：保持轻量，不要过高
文案颜色：低饱和灰蓝
数字颜色：更轻，但必须可读
分隔线透明度低于普通边框
图标颜色：统一低饱和灰蓝

## 8. 底部 tab bar
内容

保持当前三个入口：

首页
时光轴 / 时间轴
我的 / 个人中心
视觉要求
保持简洁稳定。
不要抢主卡视觉中心。
图标和文字统一风格。
选中态清楚，但不要高饱和。
注意小程序真机底部安全区。

## 9. 色彩与字体
色彩

整体色彩以冷灰白 + 低饱和蓝灰为主。

建议方向：

页面背景：#F7F8F8 / #F8FAFB
卡片背景：#FFFFFF 或略带暖白
主文字：#1A1A1A / #1F2930
副文字：#7F8C93
主按钮：低饱和蓝灰
点缀：极轻暖米色，仅用于细节，不可大面积使用
字体
Hero / 主卡标题可以带宋体或 serif 气质。
正文、状态区、tab 使用清晰系统字体。
不要混用过多字体。
中文排版要优先考虑自然断行与阅读节奏。

## 10. 禁止事项

本次首页 v2 不允许出现：

大面积照片
旧版底部书桌图
浮动加号
大面积暖黄色卡片
Dashboard 统计卡
英文状态标签
“Sealed / Arrived”
“剩余 432 天”这类强倒计时
复杂装饰纹理
强玻璃拟态
过度拟物纸张
新增无关入口
重做整体信息架构

## 11. Codex 执行约束

Codex 的任务是工程翻译，不是重新设计。

Codex 必须：

严格参考 home-v2-reference.png

优先复用现有页面逻辑
只改首页相关代码
保持其他页面不变
