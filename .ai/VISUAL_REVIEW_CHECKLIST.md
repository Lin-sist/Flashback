# Visual Review Checklist

## Structure

- page hierarchy
- module order
- spacing rhythm
- safe area
- bottom navigation / fixed action overlap

## Typography

- serif / 宋体气质
- title hierarchy
- letter spacing
- muted copy

## Paper / Vermilion Details

- paper background
- vermilion dot
- seal badge
- folded corner
- thin divider
- light shadow
- status line

## Interaction

- button active feedback
- form input focus state
- scroll bottom state
- tab selected state

## Scope Safety

- no backend
- no schema
- no business rules
- no AI
- no subscription-message
- no real multimedia
- no package / lockfile
