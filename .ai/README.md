# .ai Directory

This directory stores low-token handoff files for coding agents.

- `HANDOFF_M1_VISUAL.md`: stable M1 visual context summary
- `ACTIVE_TASK.md`: current task card
- `TASK_CARD_TEMPLATE.md`: reusable task template
- `VISUAL_REVIEW_CHECKLIST.md`: visual QA checklist
- `AGENT_LOG.md`: cross-agent handoff log

OpenSpec remains the source of truth. `.ai` files are operational summaries.
