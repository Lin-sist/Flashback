# .ai Directory

This directory stores low-token handoff files for coding agents.

- `ACTIVE_TASK.md`: current task card + **Current Progress**（跨会话交接）
- `TASK_CARD_TEMPLATE.md`: reusable task template
- `AGENT_LOG.md`: append-only execution evidence（顶部有结构化模板）
- `HANDOFF_M1_VISUAL.md` / `VISUAL_REVIEW_CHECKLIST.md`: historical visual helpers（若仍存在）

OpenSpec remains the source of truth for requirements.  
Hard collaboration rules: root `AGENTS.md`.  
Full vibecoding methodology: `Docs/agent-iteration/workflow/`.
