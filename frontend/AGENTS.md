# Frontend Agent Rules

- Stack: Uniapp + Vue 3 + Pinia.
- Target: WeChat Mini Program.
- Follow root `AGENTS.md`.
- M1 visual work must follow canonical HTML / PNG references.
- Prefer page-level fidelity before shared abstraction.
- Do not modify backend or business rules from frontend tasks.
- Do not implement real MAP / IMAGE / VOICE.
- Do not implement subscription-message behavior in M1.
- For style work, avoid full-repo scans and unrelated formatting.
- Run `npm run build:mp-weixin` when feasible after meaningful frontend changes.
