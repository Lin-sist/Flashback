# Flashback「信笺」（v3.0）视觉系统与品牌规范

> 版本：v3.0（2026-09-06）  
> 基底：现行 2.0 宣纸书信质感  
> 方向：**信笺纸 × 微液态玻璃** 单方向精修  
> 核心承诺：**“给想留下的此刻，一个位置”**

---

## 一、三层材质物理隐喻

所有界面元素与组件的设计决定必须严格向以下三层材质故事对齐：

1. **纸是世界的材质（World Material）**
   - 页面底色、信笺卡片、书信内容本体均为温暖宣纸质感。
   - 纸恒常、温暖、安静，等着接住此刻。
   - 表面层（Surface）比底色浅半档，内凹面板/书写空位比底色深半档——“东西放在纸上”必须摸得到。
   - 严禁重复摩尔纹材质贴图，仅允许 ≤3% 明度的柔和纸晕渐变。

2. **玻璃是动作与暂时之物的材质（Action & Ephemeral Material）**
   - 仅主动作按钮（玻璃药丸）、门厅入口（取景框内填充）、底部 Tab 栏（轻玻璃）、筛选 Chips 与浮层允许使用微液态玻璃。
   - **玻璃永远不承载内容本体**。
   - 具备半透明磨砂、0.5px 高光描边与按压物理厚度。
   - 每个玻璃元素必须声明“暖纸实色”降级态，适配 Skyline 渲染器与低版本 WebView。

3. **霜是被封存时间的材质（Sealed Time Material）**
   - 封存/未解锁的内容被霜层遮住（重度毛玻璃模糊＋结霜暗角遮蔽）。
   - 到达解锁时刻时霜融显影。
   - 霜是语义性的封印未解状态本体，绝非装饰性滤镜。

## 二、CSS Design Tokens 规范

```css
:root {
  /* ── 宣纸色系（纸是世界的材质） ── */
  --paper:           #faf7f2;   /* 页面主纸色：温暖米白 */
  --paper-surface:   #ffffff;   /* 卡片表面：比纸底浅半档，浮于纸上 */
  --paper-sunken:    #f3ede2;   /* 内凹面板/取景框空位：比纸底深半档，安静凹陷 */
  --paper-card:      #fcfaf6;   /* 信笺卡身：细腻微温 */
  --paper-shadow:    rgba(48, 46, 41, 0.08); /* 柔和纸阴影 */
  --paper-shadow-lg: 0 12px 32px rgba(48, 46, 41, 0.09), 0 2px 6px rgba(48, 46, 41, 0.04);

  /* ── 墨色阶梯（宋体活字印刷感） ── */

  --ink-mid:         #6b6560;   /* 中墨色：正文、说明段落 */
  --ink-light:       #9e9890;   /* 淡墨色：辅助文字、次级标签、未选中 */
  --ink-faint:       #c8c2b8;   /* 极淡墨：装饰细线、取景框标记、边框 */

  /* ── 朱砂印色（唯一的有彩色，全屏不超过三处） ── */
  --vermilion:       #b5352a;   /* 朱砂红：印章、主动作聚焦、指示节点 */
  --verm-dim:        #8a271f;   /* 朱砂按压深色 */
  --verm-light:      rgba(181, 53, 42, 0.08); /* 朱砂微晕底色 */

  --space-xl: 32px;
```

## 三、玻璃剂量地图（硬约束）

| 元素 | 材质属性 | 视觉表现 | 降级态（Fallback） |
|---|---|---|---|
| **主动作按钮（留下这一刻）** | 玻璃药丸（全 App 最玻璃之物） | `background: rgba(255,255,255,0.72)`, 16px 磨砂模糊，0.5px 高光描边，按压微下沉 | 实色暖纸厚底 `#f2ece1` + 深色主墨描边 |
| **门厅入口（取景框内）** | 取景框标记 + 极淡玻璃薄片 | 四角 L 型标记 + 内部浅淡半透明填充 | 内凹浅实色暖纸 `#f3ede2` |
| **底部 Tab 栏** | 轻玻璃 | `background: rgba(250,247,242,0.85)`, 20px 磨砂，内容从底下柔和虚化穿过 | 实色 `#faf7f2` + 1px 细线边框 |
| **筛选 Chips / 弹层** | 轻玻璃 | 悬浮微磨砂药丸，激活态含朱砂红线 | 纯白卡底 + 淡墨边框 |
| **封存卡** | 霜模糊 | 语义性遮蔽本体，非装饰；中心微透，边缘重霜 | 纸色蒙版加浅灰色噪点，隐藏文字 |
| **时刻卡/信卡正文/书写页** | **纸，严禁玻璃** | 纯净纸面装裱，微浮起柔影（10–14% 不脏不平） | 保持纸面不变 |

## 四、信笺家具规范（已裁决）

1. **红圆印（封／阅／守）**：
   - 「封」：用于封存与保存（落印签名）。
   - 「阅」：用于回看态（审视过去）。
   - 「守」：用于个人中心托管凭证（数据信托）。
   - 严禁装饰性印章泛滥，同一屏幕红色点位不得超过三处。
2. **信笺折角（Dog-ear）**：
   - 仅允许出现在“信”本体（内容信卡、书信页、已保存卡）。
   - 工具栏、面板、表单、筛选区一律禁用。
3. **存档编号**：
   - 统一采用汉字间隔式（如 `存档第 三〇 号`、`存档第 九九五〇二〇二 号`）。
   - 仅在【回看详情】与【封存详情】中出现；首页与列表页坚决禁用。
4. **封存倒计时（静态期待）**：
   - 统一为静态期待（如 `即将抵达 · 2027 年夏` 或 `还有 128 天抵达`）。
   - **坚决禁止秒级跳动**，剔除时间焦虑。
5. **禁除“MEMORY”类英文小字标签**：
   - 全系统禁止装饰性无意义英文元数据；卡片质感完全依靠照片与排版承担。
6. **竖排侧注**：
   - 采用低语式文案（如 `只写给自己`），使用朱砂细字。
7. **时间语法统一为“抵达”**：
   - 彻底摒弃连续天数、欠账打卡、缺失提醒等心理压力机制。

## 五、四枚签名动效规范

1. **落印（保存）**：
   - 保存成功后当前页信卡化，红印「封」以一次真实重力下压落于卡片右下，伴随 1.5px 微微晕开的纸纤维扩散效果。
   - 搭配极轻反馈文字 `这一刻已经留下`；默认无刺耳音效、不强制跳转。
2. **融霜（抵达）**：
   - 封存信到达解锁时间后，霜从卡片边缘逐步消融退散，信笺正文逐渐清晰显影。一次性不可循环。
3. **脊线生长与节点点亮（时光轴）**：
   - 进入时光轴时长廊轻脊线自上而下顺畅生长；节点穿过视口中线时变色点亮（空心＝纯文字，实心＝含媒体）。
4. **卡片轻浮进入**：
   - 卡片随滚动一次性轻浮进入（平移 ≤8px，透明度渐现），禁用滚动劫持与视差晃动。

### 减少动态（Reduced-Motion）降级规则
当系统开启 `prefers-reduced-motion: reduce` 时：
- 红印直接清晰呈现，不执行下压和晕开过渡；
- 封存卡直接以解锁态呈现，跳过融霜过程；
- 脊线与节点初始即为点亮状态；
- 所有平移浮动动画完全关闭。
