# Proposal：Safety Response Minimum（R1）

## Summary

R1 在公开 Agent 前增加一个窄、确定性、可验证的安全例外：只有当前输入呈现高置信、第一人称、正在发生或明确将实施的自伤风险时，backend 才打断普通记录编排，返回本地固定安全响应。普通低落、失败、迷茫、比喻、否定、转述与过去经历不得被病理化。

## Why Now

- P4.2 已接受并归档；冻结蓝图下一项唯一为 R1。
- 当前 Runtime 没有入站安全判定，provider 不可用时也无法保证紧迫风险得到稳定响应。
- 国家卫健委已确认中国大陆 `12356` 全国统一心理援助热线；`110`/`120` 的紧急用途有官方依据。资源必须标注地区，不推断用户所在位置。

## Goals

1. 高置信紧迫自伤风险在 provider、memory、tool、material 之前被确定性拦截。
2. 安全响应优先现实世界行动：远离危险物、去有人的地方、联系可信任对象和紧急援助。
3. 明确 Agent 不是专业救援人员，且无法替用户通知、报警或人工接管。
4. 不把一次触发写成永久风险标签、画像、诊断或跨 session 状态。
5. 用固定合成矩阵证明正例与普通低落/否定/转述/历史表达边界。

## Non-goals

- 医疗诊断、风险评分、概率模型、LLM-as-Judge、长期风险档案或主动监控；
- 自动报警、自动联系家人、人工坐席接管或后台通知中心；
- 未成年人策略、监护人流程、全球地区资源库或定位推断；
- 真实用户危机测试、用户日记外发、真实救援演练；
- 新 API/DTO/DDL、前端页面、一级 Tab、package/lockfile 或部署改动。

## Evidence Boundary

- 离线固定合成矩阵可证明分类与编排边界，不证明临床效果。
- 真实 provider 小样本只允许使用合成文本；不得用真实用户危机内容。
- 地区资源只证明号码与用途当前可核验，不证明任意时刻一定接通。
- 本 change 不构成发布、医疗器械、专业救援或人工接管能力。
