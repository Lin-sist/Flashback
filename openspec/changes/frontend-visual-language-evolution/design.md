## 4. 材质、排版与动效候选

- 纸：内容面高不透明暖纸，墨色阶/宋体层级沿 demo；正文承载真实长文，不做绘画背景或玻璃正文卡。纹理可选，关闭纹理不影响可读。
- 玻璃：仅动作、Tab、临时浮层/筛选；优先静态边线/高光/局部投影。背景模糊与数据 SVG 噪声的目标平台支持未知，需 F-15 验证；不支持时用实色/本地轻纹理表达，不引入滤镜依赖或新包。
- 霜：只用于封存时间的展示；真实内容是否可见服从现有权限和返回字段，不能以 CSS 模糊代替后端限制。
- 字体：系统衬线与现有 fallback 优先，检查中文、长标题和缺字；不新增在线字体、下载链路或未确认的字体授权。
- 交互：纸面正文自然滚动、可选字/输入。按钮忙碌/禁用状态继续由已有业务决定。
- 翻页：当前局部样本保存为历史试验；本次正式迁移不加入自动翻页、重播按钮、3D、分页或软页引擎。
- 回弹：候选为一次轻压/恢复；demo 的 240ms 只作初值，不是平台性能结论。以目标触摸事件重新实现必要反馈，取消/离页/重复操作能清理；不等待动画才保存，不吞 tap，不循环。
- 保存/抵达：如使用落印/融霜，真实响应或已有状态先确认，再给可跳过一次反馈。原有静态提示保持；不增加自动封存、强制跳页、语音或震动。
- 低动态：可选动画关闭即为完整终态。目标平台能否读取系统偏好尚不确认；检测失败时采用静态策略，不新增设置页或宣称已支持全部系统开关。

### S0 规划与可复现基线

### S1 状态盘点与微信可行性样本

### S2 三个样板与核心闭环

先按页迁移 home → record-editor → timeline；使用已有 token/组件做最小必要调整，不一次替换所有页面壳层。编辑器以模板/样式改动为主，保留初始化、恢复、媒体上传、保存/封存、退出与 Agent 接线。三个样板视觉/状态稳定后再抽取共同布局与按压展示。

### S3 次级页面与浮层

C 我的记录/篇章 → D 个人中心/所有权/近况结果 → E 编辑与回看 Agent 浮层。每批默认只改展示层；筛选/分页/版本冲突、导出清除确认/冻结、工具确认/来源授权均不改语义。E 不触发真实 provider；需要外调先独立 Gate 3。登录新视觉与薄雾不进入本轮实施范围。

### S4 验收与回退

各批建立明确 Git 提交点；回退以撤回本批展示改动为单位，不删除业务数据/迁移数据库。出现保存失败被吞、Preview 写入放开、封存暴露、键盘遮挡主操作或性能导致操作不可用时，停止该批并恢复最后验收状态。无动画/无模糊必须能独立验收。
