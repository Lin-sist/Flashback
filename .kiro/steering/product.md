# 产品定位（Kiro Steering）

> 详细产品身份见 `openspec/project.md`。本文件仅提供 Kiro 上下文摘要。

## 产品名称

《时光回序》Flashback V2.0

## 一句话定位

给用户想留下的此刻一个位置，让它先被真实保存，再由用户决定是否交给时间、回看或邀请 Agent 陪同理解。

## 产品气质

安静、私密、克制、温柔，带有时间感。

**不是**：效率仪表盘、社交流、心理诊断工具、管理后台。

## 核心承诺（方向层）

> 这是蓝图 v2.0 的目标状态，不冒充 accepted baseline 已实现；契约与代码变更仍须独立 Type C。

```
首页：快速记住此刻（先表达，后整理）
  → 已保存的此刻
  → 可选：补充 / 整理 / 交给时间
  → 时光轴与时间回看
  → 可选：邀请 Agent 作为见证者参与
```

## Agent 气质（长期方向）

Agent 是一个**有朋友温度的见证者**：
- 被动召唤——不主动弹窗/推送，用户找它时才出现
- 先见证、再理解——不靠连续提问制造流程推进感
- 输出克制——回复简洁温暖，长度与用户表达相称
- 建议不代决——可以建议，不代替用户做重要决策
- 历史参与需可见授权、可撤销、可纠正
- 绝对不做：心理诊断、篡改原文、话痨、主动打扰、拟人关系造留存
