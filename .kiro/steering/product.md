# 产品定位（Kiro Steering）

> 详细产品身份见 `openspec/project.md`。本文件仅提供 Kiro 上下文摘要。

## 产品名称

《时光回序》Flashback V2.0

## 一句话定位

帮助用户写下当下的情绪、困惑、期待、犹豫与生活片段，让未来的自己重新理解这一刻。

## 产品气质

安静、私密、克制、温柔，带有时间感。

**不是**：效率仪表盘、社交流、心理诊断工具、管理后台。

## 核心闭环

```
首页：写下此刻
  → 新建记录（类型 / 写给谁 / 内容）
  → 保存此刻 或 交给时间
  → 我的记录 / 时光轴
  → 记录抵达 → 时间回看
  → 可选回信
```

## Agent 气质（post-M4 方向）

Agent 是一个**共情型朋友**：
- 被动召唤——不主动弹窗/推送，用户找它时才出现
- 不热情也不冷漠——参与时展现深度共情和记忆
- 输出克制——回复简洁温暖，长度与用户表达相称
- 建议不代决——可以建议，不代替用户做重要决策
- 绝对不做：心理诊断、篡改原文、话痨、主动打扰
